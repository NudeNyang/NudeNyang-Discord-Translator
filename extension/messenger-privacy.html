Privacy notice for web messenger reading translation

Web messenger reading translation is off by default. It is available only in browsers where you have given consent.

X · Discord · WhatsApp · Telegram · Messenger · Slack · Microsoft Teams · Google Messages

  • Only message bodies from the currently open conversation are sent to the separately installed NudeNyang Windows app for translation with local AI.
  • Conversation content is not sent to external translation services.
  • Conversation content and translations held by the extension are processed only in memory and deleted when you switch or close the conversation. They are not saved to disk caches, translation history, or message-body logs.
  • No message composition or sending features are used, and names and contacts are not translated automatically.
