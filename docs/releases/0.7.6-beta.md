# NudeNyang Discord Translator 0.7.6-beta

Discord에서 스크롤한 뒤 번역이 다시 나타나기까지 오래 기다리던 문제를 줄였습니다. 기호만 보낼 때 전송 통역이 끼어들거나, 이모지 창에 초대 안내가 잘못 뜨던 문제도 고쳤습니다.

## 달라진 점

- 이전에 번역한 메시지는 다른 번역이 진행 중이어도 저장된 결과를 바로 불러옵니다. 빠르게 스크롤하면 화면 밖으로 나간 미처리 메시지는 건너뛰고, 완성된 번역부터 표시합니다.
- 전송 통역을 켠 상태에서 `!?`, `…`, 이모지만 입력하고 곧바로 Enter를 눌러도 번역을 기다리지 않고 그대로 보냅니다. 일반 문장이 섞인 입력은 기존처럼 번역합니다.
- 이모지 선택기를 열었을 때 ‘브라우저에서 계속’ 초대 안내가 나타나던 문제를 수정했습니다. 실제 초대 화면의 안내와 추가 인증 시 연결을 잠시 끊는 동작은 유지합니다.

CPU 스레드 설정은 바꾸지 않았습니다. Ryzen 9 9950X3D와 Hy-MT2 1.8B로 비교했을 때 16·32스레드가 기존 6스레드보다 빠르지 않았습니다. 이미 끝난 번역을 재사용하도록 바꿔 불필요한 대기를 줄였습니다.

## 설치와 업데이트

기존 설치형 사용자는 앱의 업데이트 안내에 따라 설치하면 됩니다. 업데이트 주소와 서명 키는 그대로 유지합니다. 앱을 지우거나 설정을 초기화할 필요는 없습니다.

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.6-beta-x64-Setup.exe` | 대부분의 Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.6-beta-ARM64-Setup.exe` | Windows on ARM PC |

Windows 10·11을 지원합니다. 예전 포터블판은 자동 업데이트가 없어 설치형을 직접 받아야 합니다. 브라우저 확장은 스토어별로 별도 배포되며, 본체 업데이트로 확장 프로그램의 버전이 바뀌지는 않습니다.

버전명은 0.7.6-beta를 유지하며 GitHub 정식 최신 릴리스로 배포합니다. 앱의 업데이트 주소와 설치 파일은 기존 공개본과 같습니다.

두 설치 파일에는 자동 업데이트용 Tauri 서명을 적용하고 각각의 `.sig`와 `SHA256SUMS.txt`를 함께 제공합니다. Microsoft Authenticode 서명과는 별개이므로 Windows에서 게시자를 확인할 수 없다는 경고가 나올 수 있습니다.

## 확인한 범위

일반 테스트 785개, Rust 테스트 493개, 브라우저 E2E 199개가 통과했습니다. Rust의 실서비스·환경 전용 검사 50개는 제외했습니다. Discord 문제는 별도 테스트 화면과 모사 번역 모델로 재현했습니다. 실제 로그인 환경의 모든 동작을 확인하지는 못했습니다. ARM64도 빌드·바이너리 형식·서명까지 검사했으며 실제 장치의 설치와 업데이트는 아직 확인하지 못했습니다.
