# 0.7.14-beta 로컬 검증판

번역문 뒤에 문장을 덧붙이거나 입력창 내용을 교체한 뒤 Enter를 누르면, 기존 전송 확인 상태 때문에 추가한 문장이 번역 없이 전송될 수 있었습니다. [이슈 #8](https://github.com/NudeNyang/NudeNyang-Discord-Translator/issues/8)

이제 작성창에 넣은 번역문을 기준으로 변경된 범위를 확인합니다. 바뀐 내용에 기존 언어 판정과 번역 제외 규칙을 적용합니다. 번역이 필요한 부분은 다른 문구와 줄바꿈을 보존한 채 작성창에 다시 표시하며, Enter를 눌러 확인한 뒤 전송할 수 있습니다. 입력 내용이 전송 언어에 맞으면 그대로 전송할 수 있습니다.

인용 등 다른 언어를 그대로 보내려면 전송 메뉴에서 **이번 메시지만 원문으로 전송**을 선택하십시오. 현재 작성창 내용에 한 번 적용됩니다.

`npm run test:e2e`에서 총 209개가 통과했습니다. Chromium의 격리 작성창으로 실제 Rust 엔진, Discord용 입력 처리 스크립트와 CDP 연결을 구동했습니다. 같은 줄 추가, Shift+Enter로 줄바꿈 후 추가, Ctrl+A로 교체, 번역 대기 중 Enter 재입력, 원문 한 번 전송을 검사했습니다. 번역 모델과 Discord 작성창은 모사했습니다.

`npm test`, 격리 데이터 폴더의 Rust 테스트 585개, Rust 포맷 검사와 Windows x64 로컬 실행 파일 빌드도 통과했습니다.
