# 0.7.9-beta 개발자판

번역 엔진의 고급 설정에 **번역 결과 검사 건너뛰기**를 추가했습니다. 기본값은 꺼짐이며,
평문 코드나 고유명사가 불필요하게 재번역될 때 켤 수 있습니다.
기존 설정의 실제 동작은 유지하며 스위치의 표시 방향만 반대로 바꿨습니다.

- 스위치를 켜고 꺼도 설명은 바뀌지 않습니다.
- 건너뛰기를 켜도 빈 문자열이나 공백뿐인 응답은 정상 번역으로 저장하지 않습니다.
- 건너뛰기를 끄면 검사 없이 저장한 캐시를 재사용하지 않고 결과를 다시 검사합니다.
- 스크린리더가 스위치의 이름과 설명을 함께 읽도록 연결했습니다.

PR #4의 설정 기능을 바탕으로 수정한 로컬 개발자판입니다.
GitHub 릴리스와 공개 자동 업데이트 목록은 변경하지 않습니다.


## 초기 개발자판 검증

- 빈 응답·공백 응답 회귀 테스트는 수정 전 실패했고 수정 후 통과했습니다.
  검사 켜짐·꺼짐 모두 빈 결과를 거부하고, 이후 정상 결과만 캐시에서 재사용하는지 확인했습니다.
- `cargo test --manifest-path src-tauri/Cargo.toml --locked`: 517개 통과, 환경 전용 50개 제외.
- `npm test`: 790개 통과.
- `npm run test:e2e`: 전체 203개 통과.
- 설정 화면 Chromium E2E: 8개 통과. 기본값, 고정 설명, 접근성 이름, 키보드 조작을 포함합니다.
- `npm run test:locales`: 28개 언어, 695개 문구 검사 통과.

테스트는 모사 서버와 페이지를 사용합니다. 실제 유료 번역 API와 ARM64 실기기에서의
실행은 검사하지 않았습니다. DOM 수집 경로는 변경하지 않았으며 공개 웹 표본 검사는
이번 작업에 포함하지 않았습니다.


## 건너뛰기 표시로 변경한 뒤 검증

`npm test` 790개와 설정 화면 E2E 9개를 통과했습니다. 기본 꺼짐, 클릭 시 실제 검사
설정과 반대로 저장되는 동작, 이전 설정을 불러온 뒤의 표시와 재실행 시 유지 여부를
확인했습니다. 28개 언어 문구 검사와 Rust 포맷 검사도 통과했습니다.
이번 후속 변경은 설정 화면에 한정되어 Rust 전체 테스트와 확장 전체 E2E는 다시
실행하지 않았습니다. 위의 517개·203개 결과는 초기 개발자판 검증 기록입니다.
