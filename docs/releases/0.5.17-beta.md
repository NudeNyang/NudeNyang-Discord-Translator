# NudeNyang Discord Translator 0.5.17 Beta

이번 오픈 베타는 번역 엔진 초기 설정 안내를 개선했습니다. 받은 메시지와 보내는 메시지에 서로 다른 모델을 권장하는 이유와 품질 우선 외부 모델을 연결해야 하는 이유를 설정 화면에서 바로 확인할 수 있습니다.

## 이번 업데이트

- 번역 엔진 설정에서 두 번역 모델의 역할을 명확히 안내합니다.
  - 받은 메시지와 이미지는 계속 처리해야 하므로 빠른 로컬 모델을 권장합니다.
  - 보내는 메시지는 의미와 말투를 자연스럽게 전달하도록 품질 우선 CLI 모델을 권장합니다.
- 품질 우선 모델을 사용하려면 계정 연결이 필요하다는 점과 번역할 메시지 텍스트만 선택한 서비스로 전송된다는 점을 안내합니다.
- 연결 목록에서 실제로 선택한 번역 서비스에 `현재 사용` 또는 `선택됨` 상태를 표시합니다.
- 여러 외부 서비스 중 선택한 서비스 하나만 연결하면 된다는 점을 안내합니다.

## 설치와 업데이트

1. `NudeNyangDiscordTranslator-0.5.17-beta-Windows-x64-Setup.exe`를 내려받아 실행해 주세요.
2. 기존 사용자는 앱의 자동 업데이트로 같은 버전을 받을 수 있습니다.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명되어 무결성을 검사합니다. Microsoft Authenticode 코드 서명은 아직 적용되지 않았으므로 Windows 또는 브라우저가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않지만, 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있습니다. 중요한 내용은 원문과 함께 확인해 주세요.

## 다운로드 파일

- Windows x64 설치 파일
- Tauri 업데이트 서명 파일 (`.sig`)

## English summary

Version 0.5.17 Beta clarifies why received content uses a fast local model while outgoing messages are best translated with a quality-first connected model. The settings screen now explains that only the selected external service needs to be connected, identifies the service currently in use, and states that only message text selected for translation is sent to that service.

The updater artifact is signed for integrity, but Microsoft Authenticode code signing is not yet applied, so Windows or the browser may show an unverified-publisher warning.
