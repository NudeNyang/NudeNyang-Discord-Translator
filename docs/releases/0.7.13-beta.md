# NudeNyang Discord Translator 0.7.13-beta

로컬 번역기에 MiLMMT 12B를 추가했습니다. 받은 메시지, 채널명과 보내는 글에 사용할 수 있으며, 기본 모델은 Hy-MT2 1.8B를 유지합니다. MiLMMT 추가와 NAS 모델 경로 지원은 [@mydanyi의 PR #7](https://github.com/NudeNyang/NudeNyang-Discord-Translator/pull/7)을 반영했습니다.

MiLMMT Q4_K_M 모델은 선택한 뒤 약 7.3GB를 별도로 내려받습니다. GPU 사용 시 여유 VRAM 약 10GB를 권장합니다. 앱에서 지원하는 언어 중 우크라이나어는 이 모델로 번역할 수 없으며, Gemma 이용약관이 적용됩니다.

## 함께 고친 문제

굵은 글씨나 줄바꿈으로 나뉜 짧은 문장을 보낼 때 원문 언어를 감지하지 못해 번역이 중단되는 문제를 고쳤습니다. 같은 메시지의 텍스트를 참고하되 코드, URL과 이전 메시지는 언어 추론에 사용하지 않습니다.

`NUDE_TRANSLATOR_MODEL_DIR`로 NAS 등 공유 폴더에 모델을 보관할 수 있습니다. 두 PC가 같은 모델을 동시에 이어받아 임시 파일을 손상시키지 않도록 다운로드와 검증, 파일 적용, 삭제에 잠금을 추가했습니다. 다른 PC가 같은 모델 파일을 준비하거나 삭제하는 중이면 작업을 마친 뒤 다시 시도하도록 안내합니다.

강제 종료 후 `.lock` 폴더가 남았다면 공유 폴더를 사용하는 모든 PC의 앱을 종료한 뒤, 오류에 표시된 빈 잠금 폴더만 삭제하십시오. 자세한 복구 방법과 검증 범위는 [패치 기록](0.7.13-beta-local.md)에 정리했습니다.

## 설치와 업데이트

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.13-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.13-beta-ARM64-Setup.exe` | Windows on ARM PC |

버전명은 `0.7.13-beta`이며 GitHub에서는 정식 최신 릴리스로 게시합니다. 기존 설치형은 앱의 업데이트 안내에 따라 설치하면 됩니다. 업데이트 주소와 서명 키는 그대로 유지하며, 설정을 초기화할 필요는 없습니다. 설치된 브라우저 확장은 이번 업데이트로 바뀌지 않습니다.

설치 파일에는 자동 업데이트용 Tauri 서명을 제공합니다. Microsoft Authenticode 서명은 포함하지 않습니다. 파일 해시는 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 확인한 범위

번역 서비스의 서식 분할과 MiLMMT 언어 검증은 추론 결과를 대체한 테스트로 확인했습니다. 동시 이어받기는 별도 프로세스 두 개와 작은 로컬 HTTP 모델 파일로 검사했습니다. 설치된 Hy-MT2의 실제 로컬 추론과 설정 화면도 확인했습니다.

MiLMMT 실제 추론, 실제 Discord 메시지 번역, 두 PC/NAS의 동시 동작과 ARM64 기기 실행은 이번 검증에 포함하지 않았습니다. x64·ARM64 설치형의 빌드, 바이너리 형식, 업데이트 서명과 체크섬은 별도로 검증합니다.
