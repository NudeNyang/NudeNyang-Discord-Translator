# NudeNyang Discord Translator 1.0.0

1.0.0 정식 버전입니다. Discord를 여러 버전으로 실행할 때의 동작을 정리하고, 전송 통역과 메시지 수정, 웹 번역 전환에서 발생하던 문제를 고쳤습니다.

## Discord

Stable·PTB·Canary를 함께 실행할 수 있습니다. 번역 스위치와 언어·모델 설정은 공통으로 사용하며, 지금 보고 있는 Discord 창을 번역합니다. 다른 창은 열어 볼 때 이어서 처리합니다.

- 재부팅 후 PTB·Canary가 연결되지 않거나 재시작 안내가 나오지 않던 문제를 수정했습니다.
- 다른 Discord 창의 전송 통역 버튼이 깜빡이던 현상을 고쳤습니다.
- 보낸 메시지를 수정한 뒤에도 바뀐 내용을 번역합니다. 번역과 원문을 전환해도 `(수정됨)` 표시를 유지합니다.
- 전송 통역에서 여러 문단의 줄바꿈을 보존하고, 메시지 작업 메뉴와 번역 버튼이 겹치던 문제를 줄였습니다. 번역문은 입력창에서 확인한 뒤 직접 전송합니다.
- 웹 번역 요청이 이어지는 동안 Discord 번역이 오래 밀리지 않도록 처리 순서를 조정했습니다.

## 웹 번역과 사전

브라우저와 본체가 연결되는 순간 요청이 끊겨 F4가 반응하지 않던 문제를 고쳤습니다. 이 수정은 본체에 포함됩니다.

웹 번역에서는 동적으로 바뀌는 목록의 처리 지연과 일부 일본어 문장이 남는 문제를 보완했습니다. 사전 결과에서는 필요한 오프라인 사전팩을 설치할 수 있도록 안내합니다.

## 기존 사용자 업데이트

설치형 사용자는 앱에 표시되는 업데이트 안내에 따라 설치하면 됩니다. 이전 베타판과 같은 업데이트 주소와 서명 키를 사용합니다. 앱을 지우거나 설정을 초기화할 필요는 없습니다.

이번 버전을 처음 실행할 때 Discord 선택 항목만 `자동`으로 바꿉니다. 나머지 설정은 유지하며, 그 뒤 직접 선택한 Discord 버전은 다시 바꾸지 않습니다.

## 설치 파일

| 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-1.0.0-x64-Setup.exe` | 대부분의 Intel·AMD Windows PC |
| `NudeNyang-Translator-1.0.0-ARM64-Setup.exe` | Windows on ARM PC |

Windows 10·11을 지원합니다. 포터블판은 자동 업데이트를 지원하지 않으므로, 예전 포터블판을 쓰고 있다면 설치형을 직접 받아 주세요.

두 설치 파일에는 자동 업데이트용 Tauri 서명을 적용하며 `.sig`와 `SHA256SUMS.txt`를 함께 제공합니다. Microsoft Authenticode 코드 서명과는 별개이므로 Windows에서 게시자를 확인할 수 없다는 경고가 표시될 수 있습니다.

ARM64는 바이너리 형식·번들·서명을 검사했지만 실제 ARM64 장치의 설치와 업데이트는 확인하지 못했습니다. 브라우저 확장은 스토어별로 별도 배포되며, 본체 업데이트가 확장 프로그램의 버전을 바꾸지는 않습니다.
