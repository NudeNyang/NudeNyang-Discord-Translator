# NudeNyang Discord Translator 0.5.19 Beta

이번 오픈 베타에서는 제거 프로그램의 로컬 AI 모델 삭제 선택지를 복구하고, 설치 언어 선택과 GitHub 릴리스 표시 방식을 정리했습니다.

## 이번 업데이트

- 제거 프로그램에서 비어 있던 두 번째 체크박스에 `다운로드한 로컬 AI 모델 삭제하기` 안내를 표시합니다.
- 애플리케이션 데이터와 다운로드한 로컬 AI 모델을 서로 독립적으로 삭제할 수 있습니다.
- 설치할 때마다 언어 선택 창을 표시하여 이전에 저장한 언어와 관계없이 원하는 언어를 다시 선택할 수 있습니다.
- GitHub 릴리스 제목에서 버전을 가장 먼저 표시합니다.
- 새 오픈 베타 릴리스가 GitHub의 `Latest` 릴리스로 자동 지정됩니다.

## 설치와 업데이트

1. PC 환경에 맞는 x64 또는 ARM64 설치 파일을 내려받아 실행해 주세요.
2. 기존 사용자는 앱의 자동 업데이트로 같은 버전을 받을 수 있습니다.

설치하지 않고 실행하려면 같은 아키텍처의 포터블 ZIP 파일을 내려받아 압축을 푼 뒤 실행해 주세요.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명되어 무결성을 검사합니다. Microsoft Authenticode 코드 서명은 아직 적용되지 않았으므로 Windows 또는 브라우저가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64와 Windows on ARM64입니다.
- ARM64 패키지는 네이티브 바이너리 형식을 확인했지만 실제 ARM64 장치에서의 최종 동작 검증은 아직 제한적입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않지만, 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있습니다. 중요한 내용은 원문과 함께 확인해 주세요.

## 다운로드 파일

- Windows x64 설치 파일
- Windows x64 포터블 ZIP
- Windows ARM64 설치 파일
- Windows ARM64 포터블 ZIP
- Tauri 업데이트 서명 파일 (`.sig`)
- 자동 업데이트 매니페스트 (`latest.json`)
- Windows 패키지 SHA-256 목록 (`SHA256SUMS.txt`)
