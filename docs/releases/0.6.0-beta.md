# NudeNyang Discord Translator 0.6.0 Beta

0.6.0 Beta는 대화 중 모르는 표현을 바로 확인할 수 있는 사전과 개인 용어 관리 기능을 추가했습니다. 보내는 메시지는 번역까지만 도와주고 마지막 전송은 사용자가 직접 하도록 바꿨으며, Discord에서 추가 인증을 요청할 때는 인증 호환 모드로 전환됩니다.

## 사전과 개인 용어

- Discord에서 단어나 짧은 문장을 선택한 뒤 `Aa` 버튼을 누르면 별도 도구 창에서 뜻, 발음, 품사와 예문을 확인할 수 있습니다.
- 문장 앞뒤의 맥락과 언어별 활용형을 함께 살펴 여러 뜻 가운데 알맞은 뜻을 먼저 보여줍니다. 근거가 부족하면 사전의 기본 순서를 그대로 유지합니다.
- 28개 언어 카탈로그와 선택 설치형 실용 사전팩을 마련했습니다. 한국어, 영어, 일본어, 중국어를 비롯한 14개 언어팩을 앱에서 설치하거나 지울 수 있습니다.
- 자주 쓰는 표현은 개인 사전에 저장할 수 있습니다. 검색, 즐겨찾기, 정렬, 일괄 선택, 가져오기와 내보내기를 지원하며, Discord에서 고친 내용은 열린 설정 창에도 바로 반영됩니다.
- 발음은 원문 언어에 맞는 Windows 음성을 우선 사용합니다. 재생을 멈췄다가 다시 누르면 문장의 처음부터 읽습니다.

## 메시지 번역과 인증 호환 모드

- 보내는 메시지의 첫 Enter는 번역문을 입력창에 남깁니다. 번역 결과를 확인한 뒤 다시 누른 Enter만 Discord에 전달되며, 긴 문장도 자동으로 나누거나 전송하지 않습니다.
- 받은 메시지는 번역할 원문 언어를 직접 고를 수 있습니다. 선택을 바꾸면 기다리지 않고 바로 저장됩니다.
- Discord가 추가 인증 화면을 표시하면 NudeNyang은 입력 충돌을 막기 위해 번역 파이프를 분리합니다. 일반 Discord에서 인증을 마친 뒤 `NudeNyang 다시 연결`을 선택하면 Discord를 다시 시작하고 번역 연결을 복구합니다.
- 인증 안내를 닫아도 설정 창 위쪽에 재연결 버튼이 남습니다. 취소하거나 연결에 실패했을 때도 다시 시도할 수 있습니다.

## 다듬은 부분

- 사전 결과를 Discord 창 밖의 독립 도구 창으로 옮겨 긴 뜻과 작은 창에서도 내용이 잘리지 않게 했습니다.
- 개인 사전의 편집, 삭제와 실시간 동기화 과정에서 발생하던 경쟁 상태를 수정했습니다.
- 다의어 자동 번역에서 한 묶음의 실패가 다른 뜻까지 가리던 문제를 고쳤습니다.
- Windows 발음 시작 감지와 긴 문장 재생을 안정화했습니다.
- 설정 창의 기본 폭, 카드 여백, 토글 정렬과 다국어 글자 잘림을 손봤습니다.
- 모든 인터페이스 언어에서 제품명을 `NudeNyang`으로 통일했습니다.

## 설치

- 일반 Intel·AMD Windows PC: `NudeNyang-Translator-0.6.0-beta-x64-Setup.exe`
- Windows on ARM PC: `NudeNyang-Translator-0.6.0-beta-ARM64-Setup.exe`

공개 배포에는 자동 업데이트를 지원하는 설치형만 포함합니다. 포터블판은 제공하지 않습니다. ARM64 설치형은 네이티브 바이너리 형식을 검사하지만 실제 장치에서의 검증 범위는 x64보다 제한적입니다.

Discord 업데이트로 화면 구조가 바뀌면 연결이나 번역이 일시적으로 동작하지 않을 수 있습니다. 중요한 번역은 원문과 함께 확인해 주세요.

## English summary

Version 0.6.0 Beta adds a selection dictionary with installable offline packs, contextual sense ordering, native speech, and full personal-term management. Outgoing translation now leaves the translated text in the composer and never sends it automatically. Verification compatibility mode detaches the translation pipe during additional Discord verification and reconnects only when the user requests it. This release also improves dictionary synchronization, pronunciation, layout, and multilingual UI consistency.
