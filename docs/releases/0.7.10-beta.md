# 0.7.10 Beta 개발자판

Discord에 연결된 상태에서 다른 창을 사용하면 `연결 확인 필요`가 뜨던 문제를 수정했습니다.
재연결 후 남아 있던 이전 오류를 지우고, 연결이 유지되는 동안에는 `Discord 창 대기 중`을
표시합니다. 상태 표시의 빨간 점도 같은 기준으로 바뀝니다.

Discord로 돌아갔다가 다시 다른 창을 열어도 이전 경고가 나타나지 않습니다.
실제로 연결에 실패하거나 추가 인증이 필요한 경우에는 기존 안내를 표시합니다.
번역 모델 오류도 계속 표시합니다.

이번 버전은 로컬 개발자판입니다. x64와 ARM64 설치형을 함께 생성하며,
개발자 실행본과 기존 바로가기를 0.7.10-beta로 맞춥니다.
공개 다운로드와 자동 업데이트는 현재 공개된 0.7.9-beta를 유지합니다.

수정 전 실패한 재현 검사와 동작 수정 후 전체 E2E 결과는
[연결 상태 표시 기록](../DISCORD_CONNECTION_STATUS_INVESTIGATION.md)에 정리했습니다.
