# NudeNyang Discord Translator 0.7.10-beta

Discord에 연결된 상태에서 다른 창을 사용하면 `연결 확인 필요`가 뜨던 문제를 수정했습니다. 재연결에 성공해도 이전 오류가 남아 경고와 빨간 점이 표시되는 경우가 있었습니다.

연결이 유지되는 동안 다른 창을 보고 있으면 `Discord 창 대기 중`을 표시합니다. Discord로 돌아갔다가 다시 다른 창으로 옮겨도 이전 경고가 나타나지 않습니다. 실제 연결 실패와 추가 인증, 번역 모델 오류는 계속 안내합니다.

## 설치와 업데이트

버전명은 `0.7.10-beta`이며 GitHub에서는 정식 최신 릴리스로 배포합니다. 기존 설치형 사용자는 앱의 업데이트 안내에 따라 설치하면 됩니다. 업데이트 주소와 서명 키는 그대로 사용하므로 설정을 초기화하거나 앱을 먼저 지울 필요는 없습니다.

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.10-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.10-beta-ARM64-Setup.exe` | Windows on ARM PC |

예전 포터블판은 설치형을 직접 받아 주세요. 브라우저 확장 버전은 그대로입니다. 두 설치 파일에 적용하는 자동 업데이트 서명은 기존 키를 사용하며, Microsoft Authenticode 서명과는 별개입니다.

## 확인한 범위

재연결 뒤 다른 창을 사용하거나 Discord로 돌아갔다가 다시 창을 바꾸는 경우를 검사했습니다. 실제 연결 실패 안내도 유지됩니다. 수정 전 재현과 테스트 결과는 [연결 상태 표시 기록](https://github.com/NudeNyang/NudeNyang-Discord-Translator/blob/main/docs/DISCORD_CONNECTION_STATUS_INVESTIGATION.md)에 정리했습니다. 검사는 격리 문서와 모사한 OS 상태·번역 모델을 사용했습니다.

ARM64는 빌드·바이너리 형식·업데이트 서명을 검증합니다. 실제 ARM64 장치에서 설치와 업데이트를 실행한 검증은 포함하지 않습니다.
