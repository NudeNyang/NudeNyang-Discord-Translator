# NudeNyang Discord Translator 0.7.12-beta

CodeBuddy 설정 안내를 정리했습니다. 개인 환경에서 사용하던 서비스 이름을 공통 안내에서 빼고, 선택한 모델과 서비스에 따라 사용량이 달라진다는 설명으로 바꿨습니다. 다른 언어의 안내와 관련 문서에도 같은 내용을 반영했습니다.

모델 목록은 계속 설치된 CodeBuddy CLI에서 읽어 옵니다. 저장한 모델 선택, 번역 방식, 연결 버튼과 설정 화면 배치는 그대로입니다.

PR #6에서 빠진 모델 ID 검사도 보완했습니다. 개인 설정과 무관한 테스트 전용 이름으로, 콜론·슬래시·마침표 등이 포함된 ID가 설정 저장부터 CLI 전달까지 바뀌지 않는지 확인합니다.

## 설치와 업데이트

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.12-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.12-beta-ARM64-Setup.exe` | Windows on ARM PC |

버전명은 `0.7.12-beta`이며 GitHub에서는 정식 최신 릴리스로 게시합니다. 기존 설치형은 앱의 업데이트 안내에 따라 설치하면 됩니다. 업데이트 주소와 서명 키는 그대로 사용하므로 설정을 초기화하거나 앱을 먼저 지울 필요는 없습니다. 예전 포터블판은 설치형을 직접 받아 주세요.

설치된 브라우저 확장은 이번 Windows 앱 업데이트로 바뀌지 않습니다. 자동 업데이트 서명은 Microsoft Authenticode 서명과 별개입니다.

## 확인한 범위

모델 ID 처리는 테스트용 CLI 도움말과 응답으로 검사하며, 설정 화면은 밝은·어두운 테마와 여러 화면 폭에서 확인합니다. 실제 CodeBuddy 계정의 번역 호출은 포함하지 않습니다.

ARM64는 빌드·바이너리 형식·업데이트 서명을 검증합니다. 실제 ARM64 장치에서 설치와 업데이트를 실행한 검증은 포함하지 않습니다.
