# NudeNyang Discord Translator 0.7.3 Beta

웹 확장 0.7.8과 함께 쓸 Windows 본체입니다. 본체와 확장의 패치 버전은 따로 관리합니다.

## 웹 확장 연결

- Chrome·Whale·Firefox의 설치·연결 상태를 브라우저별로 표시합니다.
- Chrome·Whale의 공식 스토어 페이지를 열거나 Native Messaging 연결을 복구할 수 있습니다. 확장을 자동 설치하거나 브라우저 권한을 대신 허용하지 않습니다.
- Whale 스토어 설치본의 확장 ID를 본체 연결 허용 목록에 추가했습니다.
- 확장 백그라운드가 시작되거나 브라우저와 본체 사이를 오갈 때 연결을 확인합니다. 주기적인 알람으로도 확인하며 일시적으로 실패하면 짧은 간격으로 다시 시도합니다. 새 응답은 본체 화면에 바로 반영합니다. 페이지 본문을 읽거나 번역 모델을 준비하지 않습니다.
- 브라우저마다 파란 `연결` 또는 빨간 `연결 해제` 버튼 하나를 표시합니다. 연결을 해제하면 해당 브라우저의 모든 프로필에서 본체 사용이 중지됩니다. 다른 브라우저·Discord 설정과 개인정보 동의는 그대로 남습니다. 확장을 삭제하거나 이미 표시된 번역문을 강제로 복원하지 않습니다. 다시 연결할 때 재설치할 필요는 없습니다.
- Firefox 설치 안내는 AMO 심사 상태에 따라 제한됩니다. 심사용 확장과 이미 설치된 개발 확장의 본체 연결은 별도로 확인할 수 있습니다.
- 웹 번역 설정은 기본 설정 → 브라우저 연결 → 사이트별 동작 순서로 정리했습니다. 공식 브라우저 아이콘을 쓰고 연결 버튼도 간결하게 바꿨습니다. 연결 버튼의 도움말이 카드 밖에서 잘리던 문제도 수정했습니다.
- 업데이트 후 기존 설정을 처음 불러오면 웹 번역 토글만 한 번 꺼집니다. 나머지 설정은 보존합니다. 웹 번역을 다시 켜면 앱을 재시작해도 켜진 상태로 유지됩니다. 사용할 브라우저가 이미 연결되어 있으면 설치 안내와 화면 이동을 생략합니다. 웹 메신저의 기존 개인정보 동의는 변경하거나 대신 허용하지 않습니다.
- 확장 팝업의 중복 `원문 보기` 버튼을 없애고 토글·F4로 전환하도록 정리했습니다. 개인정보 동의가 필요할 때는 상단에 안내 카드를 띄웁니다. 평소에는 설정·개인정보 관리 버튼을 한 줄로 표시합니다.
- 오래 열린 웹페이지에서 F4를 눌러도 반응이 없다가 팝업을 열어야 번역되던 문제를 수정했습니다. 끊어진 탭 연결을 자동으로 복구하고 번역을 켜기 전에 최신 본체 상태를 확인합니다. 켜기 응답을 기다리는 중에도 다시 F4를 눌러 끌 수 있으며 끄기·동의 철회·페이지 이동 뒤에는 이전 요청을 적용하지 않습니다.
- Chrome·Whale의 탭 자동 복구에 필요한 HTTP/HTTPS 사이트 권한을 명시했습니다. 기존 웹페이지 번역 범위와 같으며 브라우저가 권한 확인을 요청할 수 있습니다. 개발자 모드에서는 확장을 새로고침해야 적용됩니다.

## 웹 메신저 읽기 번역

- 본체에서 기능을 켜고 각 브라우저에서 명시적으로 동의해야 현재 열린 지원 대화를 번역합니다.
- 대상은 X DM, Discord web, WhatsApp Web, Telegram Web, Messenger, Slack, Microsoft Teams, Google Messages의 식별 가능한 대화 화면입니다. 대화 목록·연락처·작성 중인 입력·메시지 전송·첨부 파일은 제외합니다.
- 로컬 Hy-MT2·TranslateGemma 모델만 사용하며 개인 대화를 외부 번역기로 자동 전환하지 않습니다.
- 개인 메시지와 번역문은 임시 메모리에서 처리하며 일반 디스크 캐시·번역 기록·본문 로그에 저장하지 않습니다.
- X의 최신 채팅 구조를 인식하고 가상 스크롤로 첫 메시지가 교체되거나 화면 밖으로 이동할 때 같은 대화의 번역이 초기화되는 문제를 수정했습니다.
- 웹 Discord는 현재 대화의 메시지와 링크 미리보기 텍스트, 현재 서버의 보이는 채널명을 번역합니다. 이미지 OCR이나 링크 대상 페이지 수집은 포함하지 않습니다.
- 추가된 번역 범위를 확인하는 동의 버전 2가 필요합니다. 기존 동의만으로 새 범위를 허용하지 않습니다.
- 동의 없이 F4·팝업·사이트 자동 번역을 시도하면 열린 대화 화면에도 동의가 필요한 이유와 안내 버튼을 표시합니다. 이 단계에서는 메시지를 수집하거나 전송하지 않습니다. 안내를 닫은 뒤에는 스크롤할 때마다 다시 뜨지 않습니다. 직접 번역을 다시 시도하면 안내도 다시 표시됩니다.

## Windows 자동 업데이트

- x64와 ARM64 설치형을 모두 기존 키로 업데이트 서명합니다. 기존 업데이트 주소에서 두 아키텍처의 다운로드·서명을 함께 확인할 수 있습니다.
- 설치형·서명·업데이트 항목이 누락되거나 서로 맞지 않으면 배포를 중단합니다. 업로드한 파일까지 확인한 뒤 업데이트 목록을 갱신합니다.
- GitHub 프리릴리스 분류와 앱의 자동 업데이트 지원은 별개입니다. 정식 최신 릴리스로 승격하거나 업데이트 주소·키를 바꾸지 않습니다.

## 기타

- Discord 구형 도메인에서 앱 연결이 실패하는 문제를 수정했습니다.
- 일반 웹 번역의 공개 본문 추출, 같은 출처 새 탭의 번역 상태 유지, 제한된 YouTube 임베드 제목 번역을 개선했습니다.
- X 기사 카드 미리보기의 번역 누락을 수정했습니다. 일반 문서에서는 줄바꿈·링크·강조가 섞인 본문과 지원하는 공개 메뉴·검색 라벨의 수집을 개선하고 긴 문단이 누락되거나 인라인 글자가 중복 번역되는 문제를 줄였습니다. 입력값·가격·계정 영역과 숨긴 글자는 제외합니다.
- 같은 출처의 새 탭·팝업은 자체 선택이 없을 때만 부모 탭의 켜기·끄기 상태를 이어받습니다. 다른 출처나 차단된 페이지에는 적용하지 않습니다. YouTube 임베드는 보이는 제목만 번역하며 자막·음성·채널명·이미지는 대상이 아닙니다.
- 이번 버전에는 개인정보 보호 수준 개정이나 사이트 어댑터의 대규모 리팩토링을 포함하지 않습니다.

## 설치와 제한

- Windows 10·11용 x64 설치형과 ARM64 설치형을 제공합니다. 포터블판은 공개하지 않습니다.
- ARM64 바이너리 형식·번들 구성·업데이트 서명을 검증합니다. 다만 실제 ARM64 장치에서 설치·업데이트를 실행해 보지는 못했습니다.
- 업데이트 서명은 Microsoft Authenticode 코드 서명과 별개입니다. 현재 설치 파일은 Authenticode 미서명이며 Windows 경고가 표시될 수 있습니다.
- 로컬 번역 모델은 앱에서 별도로 준비해야 합니다. 일반 웹 번역에 외부 공급자를 선택하면 해당 서비스의 계정·이용 조건이 적용될 수 있습니다.
- 확장 0.7.8은 각 스토어의 심사를 거쳐 배포됩니다. 본체가 공개되어도 확장이 아직 심사 중일 수 있습니다.
- 사이트 화면 구조를 인식하지 못하는 영역은 원문으로 남습니다. 지원 메신저 전부를 실제 계정 환경에서 검증한 상태는 아닙니다.

이 버전은 GitHub 프리 릴리스로 배포합니다.
