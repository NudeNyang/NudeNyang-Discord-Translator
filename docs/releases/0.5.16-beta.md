# NudeNyang Discord Translator 0.5.16 Beta

이번 오픈 베타는 설치·제거 경험과 백그라운드 실행을 다듬었습니다. 앱 데이터와 대용량 로컬 AI 모델을 서로 독립적으로 관리할 수 있고, 시작할 때 보이던 명령 프롬프트 창을 숨겼습니다.

## 이번 업데이트

- 제거 프로그램에 **다운로드한 로컬 AI 모델 삭제하기** 선택지를 추가했습니다.
  - 애플리케이션 설정·기록과 Hy-MT2·PP-OCR 모델을 서로 독립적으로 보존하거나 삭제할 수 있습니다.
  - 두 선택지는 기본적으로 선택되지 않아 사용자가 명시적으로 고른 데이터만 삭제합니다.
- Codex CLI, Discord 연결 도우미와 로컬 `llama-server`를 백그라운드에서 시작할 때 명령 프롬프트 창이 나타나지 않도록 보강했습니다.
- 설치 프로그램을 NudeNyang Discord Translator의 라이트 디자인으로 개편했습니다.
  - Windows 표시 언어를 우선 감지합니다.
  - 자동 감지가 맞지 않으면 설치 화면에서 언어를 직접 바꿀 수 있습니다.

## 설치와 업데이트

1. `NudeNyangDiscordTranslator-0.5.16-beta-Windows-x64-Setup.exe`를 내려받아 실행해 주세요.
2. 기존 사용자는 앱의 자동 업데이트로 같은 버전을 받을 수 있습니다.
3. 제거할 때 로컬 모델을 남겨두면 다시 설치한 뒤 기존 모델을 재사용할 수 있습니다.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명되어 무결성을 검사합니다. Microsoft Authenticode 코드 서명은 아직 적용되지 않았으므로 Windows 또는 브라우저가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않지만, 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있습니다. 중요한 내용은 원문과 함께 확인해 주세요.

## English summary

Version 0.5.16 Beta adds an independent uninstaller option for downloaded Hy-MT2 and PP-OCR models, so application data and large local AI files can be kept or removed separately. Background Codex CLI, Discord helper, and `llama-server` processes now start without flashing a command window. The installer also adopts the app's light visual design, detects the Windows display language, and provides a manual language selector.

The updater artifact is signed for integrity, but Microsoft Authenticode code signing is not yet applied, so Windows or the browser may show an unverified-publisher warning.
