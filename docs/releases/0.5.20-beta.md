# NudeNyang Discord Translator 0.5.20 Beta

이번 오픈 베타에서는 Gemini·Claude CLI의 최신 모델과 호환되도록 모델 선택 방식을 수정하고, Discord 번역 연결을 사용자가 직접 복구할 수 있는 수동 재시작 버튼을 추가했습니다.

## 이번 업데이트

- Gemini 번역을 시작할 때 Antigravity CLI가 제공하는 모델 목록에서 최신 Gemini Flash Low 모델을 자동으로 선택합니다.
- 더 이상 지원되지 않는 `flash` 모델 별칭과 별도 `--effort low` 조합 때문에 번역이 시작되지 않던 문제를 수정했습니다.
- Claude는 날짜가 고정된 모델 ID 대신 Claude Code가 제공하는 최신 `haiku` 별칭을 사용합니다.
- ChatGPT는 로그인한 계정의 사용 가능 모델 목록을 확인하여 기본 모델까지 자동으로 선택하는 기존 방식을 검증했습니다.
- 번역 기능이 켜져 있지만 Discord 연결이 끊긴 경우 설정창 상단에 `Discord 재시작` 버튼을 표시합니다.
- 수동 재시작 전에 작성 중인 메시지와 통화가 종료될 수 있음을 확인하고, 재시작 전 번역 사용 상태를 그대로 유지합니다.

## 설치와 업데이트

1. 일반 Intel·AMD PC는 `NudeNyang-Translator-0.5.20-beta-x64-Setup.exe`를 내려받아 실행해 주세요.
2. Windows on ARM PC는 파일명에 `ARM64`가 표시된 설치 파일을 사용해 주세요.
3. 설치하지 않고 실행하려면 같은 아키텍처의 포터블 ZIP 파일을 내려받아 압축을 푼 뒤 실행해 주세요.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명되어 무결성을 검사합니다. Microsoft Authenticode 코드 서명은 아직 적용되지 않았으므로 Windows 또는 브라우저가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64와 Windows on ARM64입니다.
- ARM64 패키지는 네이티브 바이너리 형식을 확인하지만 실제 ARM64 장치에서의 최종 동작 검증은 제한적입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않지만, 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있습니다. 중요한 내용은 원문과 함께 확인해 주세요.

## 다운로드 파일

- `NudeNyang-Translator-0.5.20-beta-x64-Setup.exe` — 일반 Intel·AMD PC용 설치형
- `NudeNyang-Translator-0.5.20-beta-x64-Portable.zip` — 일반 Intel·AMD PC용 무설치형
- `NudeNyang-Translator-0.5.20-beta-ARM64-Setup.exe` — Windows on ARM PC용 설치형
- `NudeNyang-Translator-0.5.20-beta-ARM64-Portable.zip` — Windows on ARM PC용 무설치형
- `NudeNyang-Translator-0.5.20-beta-x64-Setup.exe.sig` — x64 자동 업데이트 검증용 서명
- 자동 업데이트 매니페스트 (`latest.json`)
- Windows 패키지 SHA-256 목록 (`SHA256SUMS.txt`)

`Setup`은 설치형, `Portable`은 압축을 풀고 바로 실행하는 무설치형입니다. 현재 자동 업데이트는 x64 설치형만 사용하므로 `.sig`도 x64 설치형에만 제공하며, 나머지 수동 다운로드 파일은 `SHA256SUMS.txt`로 무결성을 확인할 수 있습니다.

## English summary

Version 0.5.20 Beta restores compatibility with current Gemini and Claude CLI models and adds a manual Discord restart action when the translation controller is disconnected.
