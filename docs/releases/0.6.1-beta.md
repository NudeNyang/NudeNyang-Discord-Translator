# NudeNyang Discord Translator 0.6.1 Beta

0.6.1 Beta는 Discord 배포판 선택과 닉네임 번역 제어를 개선하고, 번역할 필요가 없는 전송 메시지는 원문 그대로 보낼 수 있도록 다듬은 릴리스입니다.

## 주요 변경 사항

### Discord 연결 대상 선택

- 설정의 **Discord 선택**에서 자동(권장), Discord, Discord PTB, Discord Canary 중 연결할 배포판을 선택할 수 있습니다.
- 선택한 배포판을 전환해도 함께 실행 중인 다른 Discord 배포판은 종료하지 않습니다.
- 자동 모드에서는 지원되는 Discord 배포판을 찾아 연결합니다.

### 전송 메시지 원문 통과

- 작성한 메시지가 선택한 전송 언어와 같은 언어이면 불필요한 번역 안내 없이 원문 그대로 전송합니다.
- 문장에 다른 언어가 섞여 있으면 기존과 같이 전송 언어로 번역합니다.
- 문자가 없는 기호, 이모티콘, 이모지와 문자 이모지는 번역하지 않고 그대로 전송합니다.

### 닉네임 번역

- 받는 메시지 설정에 **닉네임 번역하기** 옵션을 추가했으며 기본값은 켜짐입니다.
- 옵션을 끄면 메시지 작성자, 다이렉트 메시지 목록, 서버 멤버 목록과 좌측 하단 계정 패널의 닉네임을 원문으로 복원합니다.
- 옵션을 켰을 때도 표시 위치에 따라 일부 닉네임이 누락되거나 중복 번역되던 문제를 수정했습니다.

## 수정 사항

- 개인 사전 항목 삭제 확인 버튼의 색상을 동작 의미에 맞게 수정했습니다.
- Discord 배포판을 바꿀 때 다른 Discord 프로세스까지 종료되던 문제를 수정했습니다.
- 계정 패널의 닉네임이 번역 옵션을 끈 뒤에도 번역된 상태로 남는 문제를 수정했습니다.
- 다이렉트 메시지와 서버 멤버 목록에서 닉네임 번역 옵션이 일관되게 적용되지 않던 문제를 수정했습니다.

## 설치 파일

- Windows x64: **NudeNyang-Translator-0.6.1-beta-x64-Setup.exe**
- Windows ARM64: **NudeNyang-Translator-0.6.1-beta-ARM64-Setup.exe**

설치 전에 Discord를 실행해 두면 첫 연결을 더 쉽게 확인할 수 있습니다. Windows가 게시자를 확인할 수 없다는 경고를 표시할 수 있으므로, 이 저장소의 GitHub Releases에서 받은 설치 파일인지 확인한 뒤 실행하십시오.

## English summary

Version 0.6.1 Beta adds explicit Discord Stable, PTB, and Canary selection; preserves unrelated Discord installations when switching targets; passes through messages that do not need translation; and makes nickname translation consistent across message authors, direct messages, member lists, and the account panel.
