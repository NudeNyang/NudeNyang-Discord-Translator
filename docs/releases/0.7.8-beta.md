# NudeNyang Discord Translator 0.7.8-beta

Discord에서 번역에 실패한 메시지를 계속 다시 요청하던 문제를 수정했습니다. 코드처럼 원문을 그대로 두어야 하는 내용이 번역 결과로 돌아오면, 품질 검사를 통과하지 못해 같은 메시지를 반복 요청하는 경우가 있었습니다.

## 달라진 점

- 품질 보완까지 실패한 메시지는 원문을 유지하고 자동 요청을 멈춥니다. 스크롤 등으로 같은 메시지가 화면에 다시 나타나도 실패 기록을 재사용합니다.
- 서버 오류 등은 첫 실패 후 2초, 두 번째 실패 후 4초 기다린 뒤 재시도합니다. 세 번째 처리에서도 실패하면 멈춥니다. 긴 메시지의 분할 번역이나 서비스 내부 재시도 때문에 실제 API 호출 횟수는 더 많을 수 있습니다.
- 실패한 메시지가 있어도 다른 메시지의 번역은 계속됩니다. 원문을 수정하거나 번역을 껐다 켜면 다시 시도할 수 있습니다. 번역 엔진이나 언어 설정을 바꿔도 새로 처리합니다.

실패 기록은 최근 1,024개까지 메모리에만 보관합니다. 앱을 다시 시작하거나 오래된 기록이 밀려나면 해당 메시지를 다시 시도할 수 있습니다. 원문 유지 결과를 정상 번역으로 저장하지 않으며 코드·멘션·URL의 기존 보호 동작은 유지합니다.

## 설치와 업데이트

버전명은 `0.7.8-beta`이며 GitHub에서는 정식 최신 릴리스로 배포합니다. 기존 설치형 사용자는 앱의 업데이트 안내에 따라 설치하면 됩니다. 설정을 초기화하거나 앱을 먼저 지울 필요는 없습니다.

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.8-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.8-beta-ARM64-Setup.exe` | Windows on ARM PC |

예전 포터블판은 설치형을 직접 받아 주세요. 이번 업데이트는 Discord 수신 메시지 처리에 적용하며 브라우저 확장 버전은 바뀌지 않습니다.

두 설치 파일은 기존 키로 자동 업데이트 서명을 적용합니다. Microsoft Authenticode 서명과는 별개라 Windows에서 게시자 확인 경고가 표시될 수 있습니다.

## 확인한 범위

모사 서버가 `while(true)`를 그대로 돌려주는 검사에서, 수정 전 약 3.6초 동안 51회 발생했던 요청이 수정 후 2회에서 멈췄습니다. 화면 재생성, 메시지 수정, 번역 껐다 켜기, 서버 오류와 복구도 검사했습니다. 실제 유료 API나 구독 CLI 계정의 사용량을 측정한 결과는 아닙니다.

ARM64는 빌드·바이너리 형식·업데이트 서명을 검증하며, 실제 ARM64 장치에서 설치와 업데이트를 실행한 검증은 포함하지 않습니다.
