# NudeNyang Discord Translator 0.7.7-beta

OpenAI 호환 API를 번역 엔진으로 사용할 수 있습니다. 직접 운영하는 서버나 호환 서비스를 연결하려면 설정의 **번역 엔진 → OpenAI 호환 API**에서 서버 주소와 모델 ID를 입력하세요. 인증이 필요한 서버에만 API 키를 넣으면 됩니다.

## 달라진 점

- OpenAI 호환 API에 요청당 문장 수, 동시 요청 수, 문맥 공유 설정을 추가했습니다. 문맥 공유를 켜면 같은 화면의 다른 메시지도 참고 문맥으로 함께 보냅니다.
- 긴 연결 설정은 필요할 때 펼쳐 볼 수 있도록 접었습니다. 펼치거나 접어도 아이콘과 이름은 움직이지 않고, 입력 중인 내용도 유지됩니다. 고급 설정은 안쪽에 따로 접지 않고 바로 표시합니다.
- ChatGPT·Claude·Gemini·DeepL의 연결 버튼과 연결 해제 버튼은 기존 위치에 두었습니다.
- API 키는 Windows 보안 저장소에 보관하며, 다른 서버 주소로 바꾸면 이전 서버의 키를 보내지 않습니다. 키만 바꿔 저장해도 실제 번역에 새 키가 적용됩니다.
- 접어 둔 입력란에 잘못된 주소나 숫자가 있으면 해당 설정을 펼쳐 수정할 수 있게 했습니다.

## 설치와 업데이트

버전명은 `0.7.7-beta`이며 GitHub에서는 정식 최신 릴리스로 배포합니다. 기존 설치형 사용자는 앱의 업데이트 안내에 따라 설치하면 됩니다. 설정을 초기화하거나 앱을 먼저 지울 필요는 없습니다.

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.7-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.7-beta-ARM64-Setup.exe` | Windows on ARM PC |

예전 포터블판은 설치형을 직접 받아 주세요. 브라우저 확장은 별도로 배포되므로 이번 본체 업데이트에 확장 버전 변경은 포함되지 않습니다.

선택한 외부 API 서버에는 번역할 텍스트가 전송됩니다. 연결 전에 해당 서비스의 요금과 데이터 처리 정책을 확인해 주세요. 로컬 모델은 기존처럼 사용할 수 있습니다.

두 설치 파일에는 기존 키로 자동 업데이트 서명을 적용했습니다. Microsoft Authenticode 서명과는 별개라 Windows에서 게시자 확인 경고가 표시될 수 있습니다.

## 확인한 범위

서버 주소 변경 시 키 재사용 방지, 키 갱신, 연결 실패와 재시도, 설정 입력 보존을 검사했습니다. 설정 화면은 밝은 테마와 어두운 테마, 좁은 창과 확대 배율에서도 확인했습니다.

API 검사는 모사 서버를 사용했으며 모든 외부 서비스와의 호환성을 확인한 것은 아닙니다. ARM64는 빌드·바이너리 형식·업데이트 서명을 검사했지만 실제 장치에서의 설치와 업데이트는 아직 확인하지 못했습니다.
