# NudeNyang Discord Translator 0.5.21 Beta

0.5.21 Beta는 Windows를 새로 설치한 PC에서 ChatGPT, Claude, Gemini 연결 준비가 중단될 수 있던 문제를 고쳤습니다.

## 달라진 점

- Node.js LTS, Claude Code, Google Antigravity CLI를 자동으로 설치할 때 WinGet Community Repository를 명시적으로 사용합니다.
- Microsoft Store 소스의 인증서 확인이 실패하더라도 필요한 CLI 패키지를 다른 소스에서 찾느라 설치 전체가 중단되지 않습니다.
- 여러 WinGet 소스에서 이름이 같은 패키지를 찾았다는 안내와 함께 연결이 실패하던 문제를 해결했습니다.

## 설치와 업데이트

1. 일반 Intel·AMD PC에서는 `NudeNyang-Translator-0.5.21-beta-x64-Setup.exe`를 내려받아 실행해 주세요.
2. Windows on ARM PC에서는 파일명에 `ARM64`가 표시된 설치 파일을 사용해 주세요.
3. 0.5.20 Beta x64 설치형을 사용 중이라면 앱의 자동 업데이트로 0.5.21 Beta를 받을 수 있습니다.

자동 업데이트를 지원하지 않는 포터블판은 배포를 종료했습니다. 이 릴리스는 PC 아키텍처에 맞는 설치형을 사용해 주세요. ARM64판은 이번 버전에서 자동 업데이트를 지원하지 않습니다.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명하며, 앱은 이 서명으로 파일이 바뀌지 않았는지 확인합니다. Microsoft Authenticode 코드 서명은 SignPath Foundation 신청을 준비 중이며, 이번 릴리스에는 아직 적용되지 않았습니다.

## Code signing policy

이 릴리스는 아직 Microsoft Authenticode 서명이 적용되지 않았습니다. 승인 이후의 공식 서명 릴리스에는 “Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/)” 고지를 적용합니다. 역할, 빌드 출처와 검증 기준은 프로젝트의 [Code signing policy](https://github.com/NudeNyang/NudeNyang-Discord-Translator/blob/main/CODE_SIGNING_POLICY.md)에서 확인할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64와 Windows on ARM64입니다.
- ARM64 패키지는 네이티브 바이너리 형식을 확인하지만 실제 ARM64 장치에서의 최종 동작 검증은 제한적입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않습니다. 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있으니 중요한 내용은 원문과 함께 확인해 주세요.

## 다운로드 파일

- `NudeNyang-Translator-0.5.21-beta-x64-Setup.exe` — 일반 Intel·AMD PC용 설치형
- `NudeNyang-Translator-0.5.21-beta-ARM64-Setup.exe` — Windows on ARM PC용 설치형
- `NudeNyang-Translator-0.5.21-beta-x64-Setup.exe.sig` — x64 자동 업데이트 검증용 서명
- 자동 업데이트 매니페스트 (`latest.json`)
- Windows 패키지 SHA-256 목록 (`SHA256SUMS.txt`)

자동 업데이트는 x64 설치형만 사용하므로 `.sig`도 x64 설치형에만 제공합니다. ARM64 설치 파일은 `SHA256SUMS.txt`와 대조해 무결성을 확인할 수 있습니다.

## English summary

Version 0.5.21 Beta pins automatic Node.js, Claude Code, and Google Antigravity CLI installation to the WinGet Community Repository. A broken Microsoft Store source no longer prevents provider setup on a newly installed Windows PC. Portable packages have been withdrawn because they do not support automatic updates; use the x64 or ARM64 installer instead.
