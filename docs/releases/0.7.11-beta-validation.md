# 0.7.11-beta 소스 검증

2026-10-16, PR #5와 후속 수정사항을 합친 0.7.11-beta 소스에서 실행했다.

| 검사 | 결과 |
| --- | --- |
| `cargo test --manifest-path src-tauri/Cargo.toml --no-fail-fast` | 567개 통과, 51개 제외, 실패 없음 |
| `npm test` | 801개 통과: 웹 284개, 랜딩 38개, 확장 470개, 사전 9개. 사전 팩 검증도 통과 |
| `npm run test:e2e -- --workers=1` | 전체 208개 통과, 10.9분 |
| `PLAYWRIGHT_BROWSERS_PATH=0 npx playwright test --config web/e2e/playwright.config.mjs` | 설정 화면 14개 통과 |
| `npm run test:locales` | 28개 언어, 문구 703개 검증 통과 |
| `cargo fmt --manifest-path src-tauri/Cargo.toml -- --check` | 통과 |
| `git diff --check` | 통과 |

버전 변경 후 첫 웹 검사에서는 0.7.10으로 고정된 기대값과 화면의 버전 문자열이 남아 실패했다. 이를 0.7.11로 맞춘 뒤 전체 `npm test`를 다시 실행해 통과했다.

PR 검토 당시 실패했던 메시지 재등장·CodeBuddy 전송 한도 검사와, 후속 수정 전에 실패했던 비활성 창 재연결·버튼 정렬 검사를 포함한다. 수정 전 결과는 [PR 검토 기록](../PR_5_REVIEW.md)과 [로컬 확인본 기록](../PR_5_LOCAL_PREVIEW.md)에 남겼다.

Discord 검사는 실제 Rust 제어기와 격리 문서, 모사한 창 상태·번역 응답을 사용한다. 웹 검사는 사이트 구조를 재현한 fixture를 사용하며, 실제 로그인 사이트나 제보자 PC의 장애를 재현한 것은 아니다. 공통 웹 수집·가시성·적용 경로는 이번에 바꾸지 않았고 공개 사이트 표본 검사는 실행하지 않았다.

실제 CodeBuddy 계정 번역과 ARM64 장치 실행은 검증하지 않았다. 비 MSVC 환경의 OCR 충돌도 해결 여부를 확인하지 못했다. Windows 설치형은 별도 패키징 절차에서 두 아키텍처의 빌드·서명·체크섬을 검증한 뒤 공개한다.
