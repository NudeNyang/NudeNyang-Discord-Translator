# NudeNyang Discord Translator 0.7.14-beta

번역문 뒤에 문장을 더 쓰거나 작성창 내용을 통째로 바꾼 뒤 Enter를 누르면, 새로 쓴 글이 번역되지 않은 채 전송될 수 있었습니다. 이제 바뀐 부분에 번역이 필요하면 먼저 번역해 작성창에 표시합니다. 결과를 확인한 뒤 Enter를 한 번 더 누르면 전송됩니다. 전송 언어로 문구만 다듬었다면 그대로 보낼 수 있습니다.

언어에 관계없이 같은 규칙을 적용합니다. 인용문처럼 다른 언어를 그대로 남기고 싶을 때는 전송 메뉴에서 **이번 메시지만 원문으로 전송**을 선택하세요. 이 문제를 알려주신 @3KrisToA님, 감사합니다. [이슈 #8](https://github.com/NudeNyang/NudeNyang-Discord-Translator/issues/8)

## 설치와 업데이트

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.14-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.14-beta-ARM64-Setup.exe` | Windows on ARM PC |

기존 설치형은 앱의 업데이트 안내에 따라 설치하세요. 다운로드한 파일은 `SHA256SUMS.txt`로 확인할 수 있습니다.

## 확인한 범위

Chromium 테스트 환경에서 같은 줄에 덧붙이기, 줄을 나눠 입력하기, 전체 교체, 번역 중 Enter 연타와 원문 전송을 확인했습니다. 전체 E2E 209개가 통과했습니다. Discord 작성창과 번역 모델은 테스트용으로 대체했습니다. ARM64는 설치 파일과 업데이트 서명까지 검증했으며, 실제 ARM64 기기에서의 설치와 실행은 확인하지 못했습니다.
