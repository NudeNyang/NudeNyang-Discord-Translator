# NudeNyang Discord Translator 0.5.22 Beta

0.5.22 Beta는 Discord 연결이 끊어진 뒤 수동 재시작이 실제 재시작으로 이어지지 않던 문제를 고치고, 외부 번역 서비스의 표시 문구를 모델 버전에 의존하지 않도록 정리했습니다.

## 달라진 점

- `Discord 재시작`을 누르면 남아 있는 연결을 재사용하지 않고 Discord를 실제로 종료한 뒤 다시 실행합니다.
- 새 Discord 렌더러의 보안 연결과 번역 스크립트가 준비된 뒤에만 재시작을 완료한 것으로 처리합니다. 연결 준비에 실패하면 성공으로 표시하지 않고 다시 시도할 수 있도록 안내합니다.
- Discord 연결이 끊어진 동안 이미지 번역이 끝난 경우 결과를 조용히 버리지 않고, 연결 후 다시 시도해야 한다는 안내를 표시합니다.
- ChatGPT, Claude, Gemini, DeepL의 상태 문구에서 수시로 바뀌는 모델명을 제거했습니다. 설정 화면과 트레이에는 서비스명, 품질 우선 방식과 연결 수단만 표시합니다.
- Windows 공개 배포 파일은 자동 업데이트를 지원하는 설치형을 기준으로 정리했습니다.

## 설치와 업데이트

1. 일반 Intel·AMD PC에서는 `NudeNyang-Translator-0.5.22-beta-x64-Setup.exe`를 내려받아 실행해 주세요.
2. Windows on ARM PC에서는 `NudeNyang-Translator-0.5.22-beta-ARM64-Setup.exe`를 사용해 주세요.
3. 0.5.21 Beta x64 설치형을 사용 중이라면 앱의 자동 업데이트로 0.5.22 Beta를 받을 수 있습니다.

자동 업데이트를 지원하지 않는 포터블판은 공개 배포하지 않습니다. ARM64판은 이번 버전에서 자동 업데이트를 지원하지 않으므로 새 설치 파일을 직접 실행해 주세요.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명하며, 앱은 이 서명으로 파일이 바뀌지 않았는지 확인합니다. Microsoft Authenticode 코드 서명은 SignPath Foundation 승인 전이며 이번 릴리스에는 적용되지 않았습니다.

## Code signing policy

승인 이후의 공식 서명 릴리스에는 “Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/)” 고지를 적용합니다. 역할, 빌드 출처와 검증 기준은 프로젝트의 [Code signing policy](https://github.com/NudeNyang/NudeNyang-Discord-Translator/blob/main/CODE_SIGNING_POLICY.md)에서 확인할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64와 Windows on ARM64입니다.
- ARM64 패키지는 네이티브 바이너리 형식을 확인하지만 실제 ARM64 장치에서의 최종 동작 검증은 제한적입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않습니다. 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있으니 중요한 내용은 원문과 함께 확인해 주세요.

## 다운로드 파일

- `NudeNyang-Translator-0.5.22-beta-x64-Setup.exe` — 일반 Intel·AMD PC용 설치형
- `NudeNyang-Translator-0.5.22-beta-ARM64-Setup.exe` — Windows on ARM PC용 설치형
- `NudeNyang-Translator-0.5.22-beta-x64-Setup.exe.sig` — x64 자동 업데이트 검증용 서명
- 자동 업데이트 매니페스트 (`latest.json`)
- Windows 설치 파일 SHA-256 목록 (`SHA256SUMS.txt`)

자동 업데이트는 x64 설치형만 사용하므로 `.sig`도 x64 설치형에만 제공합니다. ARM64 설치 파일은 `SHA256SUMS.txt`와 대조해 무결성을 확인할 수 있습니다.

## English summary

Version 0.5.22 Beta makes the manual Discord restart perform a real process restart, waits for the replacement renderer connection to be ready before reporting success, and provides a recovery notice when an image translation finishes while Discord is disconnected. User-facing ChatGPT, Claude, Gemini, and DeepL labels no longer include fast-changing model version names. Portable packages are not published; use the x64 or ARM64 installer.
