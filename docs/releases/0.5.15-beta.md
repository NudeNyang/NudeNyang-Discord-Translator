# NudeNyang Discord Translator 0.5.15 Beta

NudeNyang Discord Translator의 첫 공개 오픈 베타입니다. 평소 사용하던 Discord 데스크톱 창에서 받은 메시지, 채널명, 보내는 메시지와 이미지 속 글자를 번역할 수 있습니다.

## 주요 기능

- Discord 사용자 토큰이나 비공식 Discord API를 사용하지 않는 DOM 기반 실시간 번역
- Hy-MT2 1.8B·7B와 TranslateGemma 4B를 이용한 로컬 번역
- 선택형 ChatGPT·Claude·Gemini·DeepL 연동
- PP-OCR 기반 이미지 번역과 원문/번역본 전환
- GPU 사용이 어려운 환경을 위한 CPU/RAM 실행과 자동 전환
- 28개 인터페이스 및 번역 언어
- GitHub Releases를 추적하는 서명된 자동 업데이트

## 설치와 업데이트

1. `NudeNyangDiscordTranslator-0.5.15-beta-Windows-x64-Setup.exe`를 내려받아 실행해 주세요.
2. 첫 실행에서 기본 로컬 모델을 내려받습니다. 진행률과 취소 버튼은 앱에서 확인할 수 있습니다.
3. 기존 비공개 베타 사용자는 R2에 배포되는 0.5.14 전환 버전을 거쳐 이 GitHub 오픈 베타 채널로 자동 이동합니다.

> 자동 업데이트 파일은 Tauri 업데이트 키로 서명되어 무결성을 검사합니다. Microsoft Authenticode 코드 서명은 아직 적용되지 않았으므로 Windows 또는 브라우저가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 오픈 베타 안내

- 현재 지원 대상은 Windows 10/11 x64입니다.
- Discord가 공식적으로 승인한 확장 방식은 아닙니다. Discord 업데이트에 따라 연결이나 화면 번역이 일시적으로 동작하지 않을 수 있습니다.
- 앱은 Discord 설치 파일이나 서버 데이터를 수정하지 않지만, 사용 전 [Discord 이용 약관](https://discord.com/terms)을 확인해 주세요.
- 번역은 문맥과 언어에 따라 틀릴 수 있습니다. 중요한 내용은 원문과 함께 확인해 주세요.
- 문제를 발견하면 재현 상황, 앱 버전과 개인정보를 제거한 진단 로그를 GitHub Issues에 남겨 주세요.

## English summary

This is the first public Open Beta of NudeNyang Discord Translator for Windows 10/11 x64. It translates visible Discord messages, channels, outgoing text, and images without using a Discord user token or unofficial Discord API. The release includes local Hy-MT2 translation, optional external providers, local PP-OCR image translation, CPU fallback, 28 UI languages, and signed updates through GitHub Releases.

This integration is not officially endorsed by Discord, and a Discord update may temporarily break compatibility. Translation can be inaccurate, so verify important content against the original. The updater artifact is signed for integrity, but Microsoft Authenticode code signing is not yet applied, so Windows or the browser may show an unverified-publisher warning.
