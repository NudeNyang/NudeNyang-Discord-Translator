# NudeNyang Discord Translator 0.7.0 Beta

0.7.0 Beta는 Chrome, Naver Whale 및 Firefox용 NudeNyang Web Translator의 스토어 심사와 제한된 사전 검증을 위한 Windows 동반 앱 Pre-release입니다. 확장 프로그램이 설치되지 않은 환경에서는 기존 Discord 번역 기능을 그대로 사용할 수 있으며, 웹 번역 기능은 별도의 브라우저 확장 프로그램이 연결된 경우에만 동작합니다.

## 주요 변경 사항

### Windows 엔진 기반 웹 번역

- Chrome, Naver Whale 및 Firefox 확장 프로그램이 Windows 앱의 번역 엔진을 Native Messaging으로 사용합니다.
- 원문의 문단 구조와 링크를 유지하면서 화면에 가까운 텍스트부터 번역합니다.
- 현재 탭 전환, 사이트별 자동 번역, 원문 복원, 대상 언어 선택과 페이지별 사용량 확인을 지원합니다.
- Windows 앱의 **웹 번역** 탭에서 처리 방식, 대상 언어와 외부 서비스 문자 한도를 관리합니다.

### 웹페이지 호환성과 성능

- GitHub, 검색·동영상 서비스, 소셜 피드, 크리에이터 상점과 일반 HTTP/HTTPS 문서를 지원합니다.
- 특수한 레이아웃을 사용하는 웹페이지의 작품 설명, 카테고리와 정적 안내 영역을 더 안정적으로 찾습니다.
- 긴 문서에서는 화면 근처 문단만 대기열에 넣고 스크롤이 멈춘 뒤 결과를 묶어서 적용합니다.
- 코드, 입력창, 계정·결제·주문·개인 메시지와 같은 민감 영역은 번역 대상에서 제외합니다.

### 인터페이스와 안정성

- 확장 프로그램 인터페이스가 Windows 앱과 같은 표시 언어를 사용합니다.
- `F4` 및 `Ctrl+Shift+L`로 웹 번역과 원문을 전환할 수 있습니다.
- Discord 연결 상태와 웹 번역 연결 상태를 분리해 한쪽의 오류가 다른 기능을 차단하지 않도록 했습니다.
- 로컬 모델의 번역 품질 검증과 제한된 재시도를 통합하고, 반복 실패가 무한 재시도로 이어지지 않도록 했습니다.
- Discord 언어 메뉴와 전역 단축키에서 번역 컨트롤을 더 명확하게 끌 수 있도록 개선했습니다.

## 개인정보

- 로컬 모델을 사용하면 번역할 텍스트가 PC 밖으로 전송되지 않습니다.
- 외부 번역 공급자를 사용자가 선택한 경우에만 번역에 필요한 허용 텍스트를 해당 공급자에게 전송합니다.
- 전체 HTML, 쿠키, 로그인 토큰과 방문 기록 목록은 읽거나 전송하지 않습니다.
- 자세한 내용은 [개인정보 처리방침](../../PRIVACY.md)을 확인하십시오.

## 심사용 Pre-release 안내

- 이 버전은 브라우저 확장 프로그램 심사와 제한된 사전 검증을 위한 Pre-release입니다.
- 확장 프로그램은 각 브라우저 스토어의 심사가 완료되기 전까지 일반 사용자에게 제공되지 않을 수 있습니다.
- 기존 공개 버전의 자동업데이트 대상은 계속 0.6.1 Beta로 유지됩니다.

## English summary

Version 0.7.0 Beta is a Windows companion pre-release for store review and limited testing of NudeNyang Web Translator on Chrome, Naver Whale, and Firefox. It adds native-messaging web translation, layout-preserving paragraph updates, long-page scheduling, shared UI localization, site policies, and explicit privacy boundaries. The public automatic-update channel remains on 0.6.1 Beta until the browser extensions are ready for general distribution.
