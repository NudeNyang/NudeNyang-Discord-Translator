# NudeNyang Discord Translator 0.7.2 Beta

0.7.2 Beta는 브라우저별 임시 선택자를 계속 추가하지 않고, 공개 웹페이지의 공통 문서 구조를 기준으로 텍스트 수집 범위를 확장한 시험 버전입니다.

## 웹 번역

- 제목·문단·목록·인용문·표 셀처럼 의미가 명확한 HTML 요소는 기존 문맥 단위를 유지합니다.
- `main`, `article`, `role=main`, `#main`, `#content` 등 대표적인 공개 본문 루트 안에서 `div`·`span`·링크로만 작성된 독립형 안내와 링크형 CTA를 추가로 번역합니다.
- 이미 문단 안에 포함된 강조·링크 요소는 별도 번역 블록으로 다시 수집하지 않아 문장이 잘게 나뉘는 것을 방지합니다.
- 입력 폼, 탐색·대화상자, 코드, 가격, 쿠키 동의 UI와 계정·결제·메시지 경로는 계속 제외합니다.
- DLsite, BOOTH, EISYS 공개 페이지와 일반 HTTP/HTTPS 페이지가 같은 공개 본문 수집 규칙을 공유합니다.

## 버전

- Windows 앱: `0.7.2-beta`
- Chrome·Whale·Firefox 확장: `0.7.2`

이 문서는 변경 내용을 기록하기 위한 초안이며, 원격 릴리스는 별도 요청이 있을 때만 게시합니다.
