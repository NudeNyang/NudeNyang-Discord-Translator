# 0.7.13-beta 로컬 검증판

PR #7 (`e6b05ec0e534b565e186f66284d132c669f91dee`)의 MiLMMT 12B 선택지를
로컬 검증용으로 반영했습니다. 공개 릴리스와 자동 업데이트 목록은 변경하지 않습니다.
MiLMMT의 모델·라이선스·지원 언어 안내는 PR의 변경사항을 따릅니다.

## 보완한 문제

- Discord 보내는 글을 서식과 줄바꿈 단위로 나눌 때, 같은 원문 안의 번역 가능한
  텍스트를 문자 체계별로 모아 언어를 추론합니다. `Hello **world**`, `Hello\nworld`의
  모호한 조각에도 영어 힌트를 전달합니다. 명시적으로 감지된 조각의 언어는 유지하며,
  코드·URL과 이전 메시지는 추론 근거에 포함하지 않습니다.
- 공유 NAS 모델 폴더의 검증·이어받기·해시 실패 정리·최종 이름 변경·검증 표식
  저장과 모델 삭제를 모델별 `<모델 파일>.lock` 디렉터리의 원자적 생성으로 보호합니다.
  다른 PC가 잠금을 보유하면 파일을 수정하지 않고 재시도를 안내합니다.
  준비 상태 조회는 파일을 수정하지 않습니다.

## 공유 폴더 잠금 복구

같은 공유 모델 폴더를 사용하는 모든 PC는 이 잠금 규칙을 지원하는 버전을 사용해야 합니다.
이전 버전은 잠금을 확인하지 않으므로 함께 다운로드하거나 삭제하면 안 됩니다.
SMB/NFS 서버가 디렉터리 생성을 원자적으로 처리해야 합니다. 호스트 로컬 PID나
파일 나이로 다른 PC의 잠금을 빼앗지 않습니다.

정상 종료나 처리 실패 때는 빈 잠금 디렉터리를 제거합니다. 강제 종료나 연결 장애로
잠금이 남았다면, **공유 폴더를 사용하는 모든 PC의 앱과 다운로드를 종료한 뒤**
오류에 표시된 빈 `.lock` 디렉터리만 삭제하고 다시 시도하십시오.
`.gguf`, `.part`, `.sha256` 파일은 이 복구 절차에서 삭제하지 않습니다.

## 검증 범위

회귀 테스트는 실제 `TranslationService::translate_for_discord` 경로와 MiLMMT의
실제 언어 검증·요청 생성 함수를 통과하며, 추론 결과만 fixture로 대체합니다.
동시 이어받기는 별도 OS 프로세스 두 개와 로컬 HTTP Range 서버의 6바이트 모델로
검사합니다. 중복 다운로드 차단, 이어받기와 재시도, 최종 SHA-256 표식, 강제 종료 후
잠금 보존, 삭제 차단과 해시 실패 뒤 잠금 해제를 확인합니다.

실제 두 PC/NAS에서의 파일 서버 동작과 MiLMMT 12B 추론 품질은 이 테스트에 포함하지
않습니다. MiLMMT 모델은 새로 다운로드하지 않습니다.
