# NudeNyang Discord Translator 0.7.1 Beta

0.7.1 Beta는 Chrome 웹 스토어가 발급한 NudeNyang Web Translator 항목 ID를 Windows Native Messaging 허용 목록과 동기화하는 심사용 동반 앱 Pre-release입니다.

## 주요 변경 사항

- Chrome 웹 스토어 설치본 ID `kpagdcdgomdlnnphakjakpodmgnhgaia`를 Native Messaging 허용 목록에 추가했습니다.
- 압축해제 개발 확장도 스토어 설치본과 같은 공개 키와 ID를 사용하도록 맞췄습니다.
- 전환 전에 로드한 개발 확장이 즉시 끊기지 않도록 기존 개발 ID를 임시 호환 대상으로 유지합니다.
- 웹 확장 0.1.32에서 판매자별 소개, 공개 안내·운영 공지와 안내 메뉴, 파일명과 줄바꿈 문단을 포함하도록 번역 범위를 보완하고 웹 빠른 전환키 설정을 추가했습니다.
- 같은 페이지에서 번역을 껐다 다시 켜면 원문이 바뀌지 않은 문단의 저장된 번역문을 즉시 다시 표시합니다. 원문과 번역문을 비교할 때 같은 문단을 다시 번역하지 않습니다.
- X에서 `더보기`로 펼친 게시물처럼 이미 보이는 동적 문단은 일반 스크롤 대기열보다 먼저 다시 번역합니다.
- GitHub의 접이식 설명, Google의 카드형 검색 결과, YouTube의 새 설명·추천 영상 구조와 일반 웹의 표·접이식 제목을 지원합니다.
- 긴 웹 문서에서는 화면 근처의 인접 문단을 하나의 짧은 문맥 묶음으로 처리해 로컬 모델 호출이 잘게 반복되는 현상을 줄였습니다.
- 링크와 각주가 많은 긴 문단은 웹 전용의 짧은 추론 조각으로 처리하고 조각 사이에 화면 렌더링 시간을 확보해 스크롤 중 GPU 점유로 인한 끊김을 줄였습니다. 문단 결과는 모두 준비된 뒤 한 번에 적용되며 Discord 번역 단위는 변경하지 않았습니다.
- Firefox 연결 ID와 웹 번역의 개인정보 처리 범위는 변경되지 않았습니다.

## 개인정보

- 로컬 모델을 사용하면 번역할 텍스트가 PC 밖으로 전송되지 않습니다.
- 외부 번역 공급자를 사용자가 선택한 경우에만 번역에 필요한 허용 텍스트를 해당 공급자에게 전송합니다.
- 전체 HTML, 쿠키, 로그인 토큰과 방문 기록 목록은 읽거나 전송하지 않습니다.
- 자세한 내용은 [개인정보 처리방침](../../PRIVACY.md)을 확인하십시오.

## 심사용 Pre-release 안내

- 이 버전은 Chrome 웹 스토어 확장 프로그램 심사와 제한된 사전 검증을 위한 Pre-release입니다.
- 기존 공개 버전의 자동업데이트 대상은 계속 0.6.1 Beta로 유지됩니다.

## English summary

Version 0.7.1 Beta synchronizes the Chrome Web Store extension identity with the Windows Native Messaging allowlist for review. It keeps the previous unpacked-development ID temporarily for migration, while the public automatic-update channel remains on 0.6.1 Beta.
