# NudeNyang Discord Translator 0.7.11-beta

CodeBuddy CLI를 번역 서비스에 추가했습니다. PR #5를 반영하면서 번역 재시도와 설정 화면, Discord 재연결도 함께 수정했습니다.

## CodeBuddy 번역

PC에 설치하고 로그인한 CodeBuddy CLI를 연결해 사용할 수 있습니다. 번역 엔진 설정에서 모델 목록을 불러오거나 새로 고침할 수 있으며, 선택한 모델로 받은 메시지와 보내는 글을 번역합니다. 연결 확인 시 짧은 번역 요청을 한 번 보내며, 이 요청은 해당 서비스의 사용량에 포함될 수 있습니다.

CodeBuddy 설정은 DeepL과 OpenAI 호환 API 사이에 배치했습니다. 모델 선택과 기존 연결·해제 아이콘은 펼친 영역 안에 두고, 접기 화살표는 오른쪽 끝에 맞췄습니다. 설정을 열고 닫아도 서비스 이름과 아이콘이 움직이지 않으며 선택한 모델도 유지됩니다.

## 수정한 문제

- 품질 검사를 통과하지 못해 원문으로 남긴 메시지가 스크롤 후 다시 나타날 때 번역을 반복 요청하던 문제를 수정했습니다. 같은 묶음의 정상 번역은 유지합니다. 번역을 껐다 켜거나 모델·언어를 바꾸면 다시 시도할 수 있습니다.
- 다른 앱을 사용하는 동안 Discord 연결 확인이 일시적으로 실패하면, 기존 보안 연결이 복구돼도 재접속하지 않던 문제를 수정했습니다. 메시지를 새로 읽거나 번역을 적용하는 작업은 계속 사용 중인 Discord 창에서만 수행합니다. 실제 연결 실패와 추가 인증 안내는 유지합니다.
- CodeBuddy의 연결 버튼이 구분선에 붙고 입력칸보다 오른쪽으로 나가던 배치를 수정했습니다. 연결·해제 버튼 모두 같은 여백과 정렬을 사용합니다.

## 설치와 업데이트

| 설치 파일 | 사용 환경 |
| --- | --- |
| `NudeNyang-Translator-0.7.11-beta-x64-Setup.exe` | Intel·AMD Windows PC |
| `NudeNyang-Translator-0.7.11-beta-ARM64-Setup.exe` | Windows on ARM PC |

GitHub에서는 프리릴리스로 게시합니다. 기존 설치형은 앱의 업데이트 안내에 따라 설치하면 됩니다. 업데이트 주소와 서명 키는 그대로이며, 설정을 초기화하거나 앱을 먼저 지울 필요는 없습니다. 예전 포터블판은 설치형을 직접 받아 주세요.

이번 배포는 Windows 앱 업데이트입니다. 설치된 브라우저 확장은 바뀌지 않습니다. 저장소의 확장 소스에는 CodeBuddy 전송 한도 수정도 포함했지만, 기존 확장에 적용하려면 별도의 확장 업데이트가 필요합니다.

## 확인한 범위

재시도·재연결 검사는 격리 문서, 실제 Rust 제어기와 모의 번역 응답을 사용합니다. 설정 화면은 밝은·어두운 테마, 여러 화면 폭과 연결 상태에서 검사합니다. 실제 CodeBuddy 계정으로 번역한 검증과 제보자의 PC에서 발생한 장애 재현은 포함하지 않습니다.

ARM64는 빌드·바이너리 형식·업데이트 서명을 검증하며, 실제 ARM64 장치의 설치·실행 검증은 포함하지 않습니다. 비 MSVC 환경에서 제보된 OCR 충돌은 원인이 확인되지 않아 이번 수정 항목에 포함하지 않았습니다.
