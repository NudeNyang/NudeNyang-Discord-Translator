# NudeNyang Discord Translator 0.7.4 Beta

웹 번역의 동작 범위와 개인정보 안내를 다시 정리한 프리릴리스입니다. 함께 제출할 웹 확장
버전은 0.7.11이며, 이전에 저장한 개인정보 동의를 새 범위로 자동 확대하지 않습니다.

## 웹 번역

- 웹 번역을 켜거나 끄면 현재 브라우저의 열린 탭과 새 탭에 같은 상태가 적용됩니다. 사이트별
  차단과 브라우저별 연결 해제는 그대로 우선합니다.
- 오래 열어 둔 탭에서 F4가 반응하지 않다가 팝업을 열어야 번역되던 문제를 수정했습니다.
  확장 수신기가 끊어진 경우 다시 연결한 뒤 최신 설정을 확인합니다.
- 문단과 제목뿐 아니라 구조로 구분되는 메뉴, 버튼, 설명 문구도 번역합니다. 입력값, 편집기,
  코드, 금액, 닉네임·핸들·연락처처럼 보호 대상으로 표시된 정보는 계속 제외합니다.
- 동적 페이지에서 일부 문장이 남는 경우를 줄였고, 링크·강조·줄바꿈이 섞인 문장과 링크
  미리보기의 처리도 보완했습니다.
- 팝업의 중복 `원문 보기` 버튼을 없애고 F4와 상단 토글로 전환 방식을 통일했습니다.

## 메신저와 열린 메일 읽기 번역

- 처음 사용할 때 하나의 개인정보 안내에서 일반 웹 번역과 사적 읽기 범위를 확인합니다.
  기존 웹 동의 v1과 사적 읽기 동의 v1~v4는 새 동의로 자동 승격하지 않습니다.
- 명시적으로 동의한 뒤 현재 열린 X DM, Discord 웹, WhatsApp Web, Telegram Web, Messenger,
  Slack, Microsoft Teams, Google Messages 대화의 보이는 본문을 번역할 수 있습니다.
- Discord 웹에서는 현재 서버에 보이는 채널명과 현재 대화의 링크 미리보기 텍스트도 번역합니다.
  X DM은 가상 스크롤로 메시지 요소가 교체되어도 같은 대화의 번역을 유지하도록 수정했습니다.
- Gmail과 Outlook은 현재 열어 둔 읽기 화면의 제목과 보이는 본문만 처리합니다. 메일 목록,
  발신자·수신자 UI, 연락처, 작성 중인 내용, 첨부 파일과 다른 메일은 읽지 않습니다.
- Outlook은 합성 화면과 공통 경계 검사로 확인했으며, 실제 로그인 계정의 모든 화면을 검증한
  상태는 아닙니다.

## 번역기와 보관 방식

- 일반 창의 사적 읽기는 앱에서 직접 선택한 로컬 모델 또는 외부 번역기를 사용합니다. 외부
  번역기를 선택한 경우 번역에 필요한 허용 범위의 텍스트만 해당 공급자에게 전달됩니다.
- 일반 창에서 보관하는 원문과 번역문 캐시는 Windows 사용자 계정 범위로 암호화하고 앱의
  보관 기간과 삭제 설정을 따릅니다. 시크릿 창은 디스크 캐시를 사용하지 않습니다.
- 개발자는 번역 중계 서버, 분석 서버 또는 웹페이지·대화 본문 보관 서버를 운영하지 않습니다.
  자세한 내용은 저장소의 개인정보 처리방침을 확인해 주세요.

## 설치와 제한

- Windows 10·11용 x64와 ARM64 설치형을 함께 제공합니다. 포터블판은 자동 업데이트를 지원하지
  않아 공개하지 않습니다.
- 설치형은 기존 Tauri 업데이트 키로 서명합니다. Microsoft Authenticode 코드 서명과는 별개이므로
  Windows에서 게시자를 확인할 수 없다는 경고가 표시될 수 있습니다.
- ARM64 파일의 형식, 번들 구성과 업데이트 서명은 자동으로 검사하지만 실제 ARM64 장치에서의
  설치·업데이트는 이번 릴리스에서 확인하지 못했습니다.
- 실제 로그인 사이트는 계정과 화면 배치에 따라 원문으로 남을 수 있습니다. Gmail은 한 읽기
  화면에서 확인했으며, Outlook과 지원 메신저 전체를 실제 계정으로 검증한 것은 아닙니다.
- 웹 확장 0.7.11은 Chrome·Whale·Firefox 스토어 심사를 별도로 거칩니다. 본체 프리릴리스가
  공개되어도 각 스토어의 확장 공개 시점은 다를 수 있습니다.

이 버전은 GitHub 프리릴리스로 배포합니다.
