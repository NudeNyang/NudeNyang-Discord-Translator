# 보낸 메시지를 수정한 뒤의 표시 번역

## 원인과 동작

전송 통역으로 보낸 메시지는 메시지 ID와 채널에 저장한 원문을 표시하므로 일반
메시지 번역에서 제외한다. 기존 구현은 편집 저장 후 내용이 달라져 원문 표시가
해제되어도, 저장된 메시지 ID가 있다는 이유만으로 수집과 번역 적용을 계속 막았다.
답장 인용문은 별도 수집 경로이므로 본문만 번역되지 않는 현상이 생겼다.

원문 표시 관리자 버전 21부터 현재 내용과 저장된 전송문이 같은지 확인하는
`isManagedMessage`를 제공한다. 원문 표시, 일반 메시지 수집, 번역 적용이 같은
판정을 사용한다. 편집 중인 메시지는 보호하고, 저장 후 전송문이 달라졌다면
일반 표시 번역 대상으로 돌린다. 메시지 ID가 같아도 이전 원문을 대신 보여주지 않는다.
취소하여 내용이 같아지거나 스크롤로 같은 메시지가 다시 렌더링되면 기존 원문 표시를
유지한다. 저장된 기록을 삭제하거나 실제 Discord 메시지를 다시 전송하지 않는다.

기존 관리자가 남은 렌더러는 버전 검사로 새 관리자를 주입한다. 이전 관리자만 있는
짧은 전환 구간에는 기존 제외 규칙을 유지한다. 확장 프로그램 소스와 권한은 바꾸지 않는다.

## 재현 및 검증 경계

`extension/e2e/discord-focus.spec.mjs`의 편집 회귀는 실제 Rust 컨트롤러, CDP,
DOM 스냅샷·번역 적용 스크립트와 원문 표시 스크립트를 사용한다. 프로세스·포커스와
번역 모델은 격리 Chromium fixture로 대체한다. 저장된 전송 원문은 테스트 드라이버가
제품의 원문 표시 스크립트로 전달한다. 실제 데이터베이스 기록 저장·조회 검증과는 다르다.

- 최초 원문 표시, 스크롤 재렌더링, 편집 중 입력 보호와 편집 취소를 확인한다.
- 저장한 편집 내용이 일반 번역으로 전환되는 검사는 수정 전 원문으로 남아 실패했다.
  수정 후 `[ko]` 모사 번역이 적용되어 통과했다.
- 반복 편집과 전체 OFF/ON 이후 최신 원문 복구를 확인한다.
- 지연 모델이 이전 수정 내용을 처리하는 중 다음 수정이 발생해도 최신 결과를 유지한다.

테스트는 합성 메시지만 사용하며 사용자의 실제 대화를 보내거나 수정하지 않는다.
실제 로그인 Discord에서 메시지 편집·저장을 직접 실행한 검증과 구분한다.

## 수정 표시 보존 (관리자 버전 22)

메시지 안의 `time[datetime]`은 Discord가 제공하는 수정 시각 정보다. 기존 수집기는
그 안의 `(수정됨)` 같은 문구까지 본문 조각으로 취급했다. 저장된 전송문을 비교할
때에도 이 문구가 섞였으며, 원문 보기에서 본문 전체를 숨기는 구조에는 수정 표시를
따로 유지하는 처리가 없었다.

메시지·답장에 속한 시각 정보는 수집, 번역 적용, 수동 복원과 자동 복원의 네 경로에서
같은 규칙으로 제외한다. 전송문 비교에서도 시각 정보를 빼고 본문만 비교한다.
저장된 원문을 표시할 때에는 실제 시각 노드의 문구와 `datetime`을 읽기 전용으로
함께 표시하고, 전송문 보기에서는 Discord의 기존 노드를 그대로 사용한다.
수정 표시를 임의로 생성하지 않으며 문구·시각 변경, 제거, 재렌더링을 반영한다.
원문 보기의 사본은 Discord의 툴팁 이벤트를 복제하지 않는다.

수집 재현 검사는 메시지·답장 본문에 수정 표시가 섞여 실패했다. 브라우저 재현은
수정 표시 때문에 저장된 전송문이 일치하지 않아 원문 보기가 생성되지 않으면서
실패했다. 수정 후 두 검사가 통과했다. E2E는 번역, OFF/ON, 개별 원문/전송문 전환,
수정 문구·시각 변경, 재렌더링과 표시 제거를 확인한다. 위와 동일하게 합성 DOM과
모사 번역 모델을 사용하며 실제 로그인 Discord 대화의 편집 검증은 아니다.

수정 표시 후속 검증 결과:

- `npm test`: 781개 통과. 최종 변경 후 관련 Node 검사 27개 재확인 통과.
- `npm run test:e2e`: 전체 183개 통과(3.1분).
- `cargo test --manifest-path src-tauri/Cargo.toml -- --test-threads=1`:
  485개 통과, 1개 실패, 기존 제외 50개. 기존
  `browser_session_prepares_the_display_translator_without_discord`가 실제 데스크톱
  환경을 사용하며 `!status.cdp_connected` 조건에서 실패했다. 단독 재실행에서도
  동일했다. 이번 변경은 연결 정책을 수정하지 않으며 전체 Rust 성공으로 처리하지 않는다.
- 최종 변경의 `cargo test --manifest-path src-tauri/Cargo.toml -- dom::tests` 및
  `-- outgoing::tests`: 각각 18개·15개 통과(기존 제외 2개·14개).
- `npm run test:public`: 공개 표본 5개 통과, 기사 표본 1개는 HTTP 404로 실패.
  표본을 교체하거나 접근 실패를 번역 성공으로 처리하지 않았다.
- Rust 포맷, JavaScript 구문 검사, `git diff --check`: 통과.
- `scripts/package_windows_variants.ps1`: x64·ARM64 설치형 생성 성공.
  Tauri 바로가기의 대상·작업 폴더·아이콘을 동기화하고 최신 x64 본체를 실행했다.
  실행 경로, 제품 버전 `0.7.5-beta`, x64 빌드와 배치 실행 파일의 SHA-256 일치를 확인했다.
- 사용자가 최신 본체에서 번역·원문 전환 후 실제 Discord의 `(수정됨)` 표시가
  유지된다고 확인했다. ARM64 실기기 검증 및 공개 배포는 수행하지 않았다.
