# 웹 메신저와 앱 Discord의 처리 정책 통합

현재 미공개 개발본의 전체 ON/OFF와 새 탭 동작은 [전체 웹 번역 정책](WEB_TRANSLATION_GLOBAL_SWITCH.md)을 따른다. 아래 탭별 수동 시작 설명은 이전 구현 기록이다.

2026-08-28 · `codex/web-translation-dom-refactor` · 미공개 개발 변경

## 바꾼 이유

메신저 번역 누락이 아닌 제품 정책의 문제였다. 브라우저 동의를 받았어도 본체·확장의 전용 스위치, 공급자 허용 목록, 서비스의 외부 전송 차단이 각각 작동했다. 매 요청마다 일반 캐시를 임시 캐시로 교체해 이전 번역도 재사용하지 못했다. 로그 보호와 모델 프롬프트 캐시 금지까지 같은 조건에 묶여 있었다.

사이트별 선택자 예외를 추가하거나 DOM 수집 범위를 넓히지 않고 이 정책을 변경했다.

## 사용자 경험

| 항목 | 이전 v2 | 이번 v3 |
|---|---|---|
| 메신저 사용 | 본체 전용 토글 + 브라우저 동의 | 브라우저 안내에 동의한 뒤 공통 웹 번역 설정 사용 |
| 번역기 | 로컬만 허용 | 앱에서 선택한 번역기 사용 |
| 일반 창 캐시 | 매 요청 후 폐기 | 본체 캐시 재사용, 기존 보관 기간·삭제 공유 |
| 프롬프트 재사용 | 메신저 전체에서 금지 | 일반 창은 앱과 같은 설정, 시크릿만 금지 |
| 저장 보호 | 웹 메신저 저장 안 함 | 공통 캐시의 본문·번역문을 Windows DPAPI로 암호화 |
| 시크릿 창 | 명시적 저장 메타데이터 없음 | 브라우저가 제공한 정보로 임시 메모리 경로 강제 |

추가 외부 전송/저장 토글은 만들지 않았다. 일반 창에서 DM·그룹·채널을 민감도에 따라 임의로 다르게 취급하지 않는다. 기존 닉네임·핸들·URL·연락처·코드·작성창 보호, 현재 대화 경계, 자연어 링크 문구와 공개 메뉴 번역은 그대로다.

본체 웹 번역 설정의 별도 「웹 메신저 읽기 번역」 안내 행도 제거했다. 브라우저의 개인정보 안내·동의와 실제 번역 정책은 그대로 유지한다.

## 남긴 제한과 이유

- **현재 프로필의 동의 v3**: v1/v2 안내는 외부 전송과 저장을 허용하지 않았다. 기존 동의 값은 자동 갱신하지 않는다. 거절해도 일반 웹 번역은 사용할 수 있다.
- **Firefox 선택 권한**: `personalCommunications` 거절·취소·철회를 동의로 해석하지 않는다.
- **본체 기능 확인**: `webSettings.messengerPolicyVersion === 3`일 때만 새 정책을 사용한다. 구형 본체에 개인 대화를 일반 웹 요청으로 보내지 않는다.
- **공통 OFF·사이트 정책·브라우저 연결 해제**: 사용자가 끄거나 차단한 범위를 동의가 덮어쓰지 않는다.
- **안전하게 식별된 현재 대화**: 다른 대화, 숨은 기록, 작성창, 연락처 목록을 읽지 않는다. 지원 여부를 모르는 사적 화면을 범용 수집으로 우회하지 않는다.
- **시크릿 저장 금지**: 디스크 캐시를 읽거나 쓰지 않는다. 구독 CLI의 자체 로컬 파일을 통제할 수 없어 시크릿에서는 로컬 모델 또는 DeepL만 사용한다. 일반 창의 외부 번역기 선택에는 이 제한이 없다.

## 구현 지점

- `extension/messenger-privacy.js`: 동의 v3, Firefox 권한, 송신 탭/대화 출처, 본체 기능 확인. 페이지가 보낸 `incognito`를 신뢰하지 않고 브라우저 탭 값으로 덮어쓴다. 탭 정보가 없으면 저장 불가로 취급한다.
- `extension/content.js`: 전용 토글·로컬 모델 제한 제거, 기존 DOM 보호·대화 변경·철회 시 결과 폐기 유지.
- `web/app.js`, `web/index.html`, `web/state.mjs`, `src-tauri/src/config.rs`: 전용 설정과 UI 제거. 28개 언어 개인정보 안내 갱신.
- `src-tauri/src/engine.rs`: 동의 버전 검증, 공통 웹 설정과 공급자 변경 시 기존 요청 무효화, 시크릿 요청 구분.
- `src-tauri/src/translation/service.rs`: 일반 창은 공유 캐시를 사용하고 시크릿만 메모리 캐시로 교체한다. 대화 감지 문맥은 요청 사이에 섞지 않는다. 민감한 진단 로그 억제는 유지한다.
- `src-tauri/src/cache.rs`, `cache_crypto.rs`: 본문 필드를 암호화 BLOB으로 저장한다. 기존 TEXT 본문을 트랜잭션으로 전환하고 시간·언어·키를 유지한다. 평문 행 전용 부분 색인으로 이후 시작 시 전체 기록을 다시 탐색하지 않는다.
- `src-tauri/src/diagnostics.rs`, `translation/hymt.rs`: 로그 보호와 시크릿 프롬프트 캐시 제한을 분리한다.
- `src-tauri/src/translation/subscription_cli.rs`: Codex 보조 실행 경로도 결과를 stdout 파이프로 받는다. 앱이 평문 `response.json`을 만들던 동작을 제거했다. 공급자 CLI 자체 기록까지 통제한다는 뜻은 아니다.

## 저장과 이전 데이터

기존 앱의 보관 기간은 기본 30일이며 0은 **기간 제한 없음**이다. 보관 기간에 따른 기존 정리 시점과 직접 기록 삭제 기능을 공유한다. 동의 철회나 대화 이동만으로 디스크 기록을 삭제하지 않는다고 안내한다.

DPAPI는 Windows 사용자 계정에 종속된다. 전체 SQLite 파일이나 설정·색인 메타데이터를 암호화하는 방식은 아니며, 같은 계정에서 실행 중인 다른 프로그램과 메모리 접근까지 차단하지 않는다. 이전 실행 파일은 암호화 BLOB을 읽지 못하므로 이 브랜치의 캐시 형식을 구형 실행 파일과 함께 사용하지 않아야 한다. 비 Windows에서는 OS 암호화 구현 전까지 디스크 대신 메모리 캐시를 사용한다.

외부 서비스와 구독 CLI의 자체 기록은 앱 캐시와 별도다. 전송 전에 선택한 공급자와 그 정책을 확인해야 하며 앱 기록 삭제로 공급자 기록까지 삭제되지는 않는다. 이미 전달한 외부 요청의 회수나 RAM·VRAM·OS 사본의 물리 소거를 보장하지 않는다.

## 재현과 검증

수정 전에 다음 실패를 직접 확인했다.

- Node: v2 동의 자동 수용, 새 동의/외부 공급자 차단, 전용 토글 잔존.
- 실제 Chromium MV3 E2E: 최신 동의와 외부 공급자 설정에도 본문이 원문으로 남음.
- Rust: 외부 공급자 요청이 `messenger_local_only`로 거부됨; SQLite 파일에 합성 본문이 평문으로 남음; 로그 보호가 일반 메신저의 프롬프트 재사용까지 막음.
- 최종 회귀 점검: 일반 웹의 시크릿 요청이 원문 언어 선택을 무시함; 구형 본체가 일반 시크릿 요청을 저장할 수 있음; Codex 보조 경로가 평문 결과 파일 출력을 요구함. 각각 재현 테스트 실패를 확인한 후 해당 원인을 고쳤다.

추가 검증은 기존 테스트 파일에 포함했다. 동의 v2/구형 본체 차단, 실제 승인 화면→v3 저장→번역, 8개 메신저의 외부 공급자 허용, 브라우저 소유 시크릿 정보, 암호화 이전/재열기/유사 문장 캐시/보관 기간/직접 삭제, 시크릿의 디스크 비사용과 CLI 대체 경로 차단을 검사한다.

## 심사에 관한 판단

전용 메신저 토글을 요구하는 규정으로 해석하지 않았으며, 필수적인 고지·동의·권한·철회와 저장 보호를 남겼다. 심사 통과 보장은 아니다.

- [Chrome 개인정보 FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq): 로컬 처리도 고지 대상이며, 명시적 동의와 안전한 저장/전송이 필요하다.
- [Firefox Add-on Policies](https://extensionworkshop.com/documentation/publish/add-on-policies/): 지속적인 데이터 처리의 동의와 사생활 보호 모드의 저장 제한을 확인했다.
- [Microsoft DPAPI 예제](https://learn.microsoft.com/en-us/windows/win32/seccrypto/example-c-program-using-cryptprotectdata): 사용자 계정 범위 보호와 메모리 해제를 따른다.
- [Codex 비대화형 실행](https://learn.chatgpt.com/docs/non-interactive-mode): 최종 응답은 stdout으로 받으며 `--ephemeral`로 세션 rollout 파일을 저장하지 않는다.

이번 작업은 합성 사이트/번역 응답을 사용한 실제 Chromium 확장 E2E와 Rust 테스트를 구분한다. 실제 로그인한 8개 서비스의 최신 화면 전체, 실제 외부 계정·로컬 모델 추론, Firefox/Whale 실브라우저 심사 결과를 검증했다고 주장하지 않는다. 공개 정책·스토어 등록 문구·배포 버전·본체 설치 파일은 향후 릴리스 전에 함께 갱신해야 한다. 이번 작업에서는 푸시·릴리스·스토어 제출을 하지 않는다.
