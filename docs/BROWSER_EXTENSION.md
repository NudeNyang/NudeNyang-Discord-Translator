# 브라우저 확장 프로토타입

`extension/`은 NudeNyang Windows 앱을 번역 엔진으로 사용하는 Manifest V3 확장이다. Chrome과 Naver Whale에서 같은 소스를 로드하며, 별도 모델이나 외부 번역 서버를 띄우지 않는다.

## 동작 구조

```text
지원 웹사이트의 보이는 문단
  → 확장 콘텐츠 스크립트가 허용된 텍스트 노드만 추출
  → Native Messaging
  → 설치된 NudeNyang 실행 파일의 호스트 모드
  → 실행 중인 Windows 앱의 인증된 127.0.0.1 브리지
  → 기존 표시 번역 워커와 현재 선택 모델
  → 원래 텍스트 노드에 결과 적용
```

확장은 부모 요소의 `innerHTML`이나 `textContent`를 통째로 바꾸지 않는다. 한 문단 안의 인라인 텍스트 노드를 같은 문맥으로 묶어 번역한 뒤 각 노드 값만 바꾼다. 링크, 강조, 목록, 제목과 문단의 DOM 구조는 그대로 남으며, 끄기 또는 `이 페이지 원문으로 복원`을 누르면 기록한 원문을 정확히 되돌린다.

## 개발 설치

1. 최신 NudeNyang Windows 앱을 한 번 실행한다.
2. 실행 파일에 `--register-browser-native-host`를 붙여 한 번 실행한다. 정식 설치본은 설치 과정에서 이 등록을 자동으로 수행한다.
3. Chrome은 `chrome://extensions`, Whale은 `whale://extensions`를 연다.
4. 개발자 모드를 켜고 `압축해제된 확장 프로그램을 로드`에서 저장소의 `extension` 폴더를 선택한다.
5. 브라우저를 완전히 종료했다가 다시 시작한다.

개발 중 확장 관리 화면에서 확장을 다시 로드하면 이미 열려 있던 페이지의 이전 콘텐츠 스크립트는 무효화된다. 해당 페이지도 새로 고쳐야 새 버전이 적용된다. 이전 스크립트는 무효화를 감지하면 남은 번역 대기열과 DOM 관찰을 종료하고 적용된 텍스트를 원문으로 복원한다.

확장 ID는 manifest의 공개 키로 `bdkkgjjmocmdknffadjgbljmnhdcchjl`에 고정되어 있다. Native Messaging 호스트는 이 ID만 허용한다. 스토어 배포 시 스토어가 부여한 ID가 달라지면 호스트 허용 목록과 설치 등록을 함께 갱신해야 한다.

Windows 앱이 꺼져 있거나 호스트 등록이 없으면 확장 팝업에 연결 오류가 표시된다. 앱을 실행한 뒤 페이지를 새로 고치거나 확장 토글을 다시 켜면 된다. 모델을 처음 준비하는 동안에는 확장이 잠시 기다렸다가 재시도한다.

## 사이트별 범위

| 사이트 | 번역 대상 | 의도적으로 제외하는 영역 |
|---|---|---|
| GitHub | Markdown 본문, Issue·PR·댓글·릴리스 설명 | 코드, diff, 파일 경로, SHA, 입력창 |
| BOOTH | 상품 설명, 항목 설명, 공지 | 가격·통화, 장바구니, 결제, 주문, 계정 |
| Google Search | 검색 결과 제목·요약, 지식 패널 | 검색어 입력, 계정 UI |
| YouTube | 영상 제목·설명·댓글, 열어 둔 스크립트 | 검색·댓글 입력, 채널명·핸들, Studio |
| X | 게시물과 인용 게시물 본문 | 글쓰기, DM, 핸들, 해시태그 링크 |

사이트는 수시로 DOM 구조를 바꿀 수 있다. 어댑터 선택자가 맞지 않는 영역은 억지로 번역하지 않고 원문으로 남기는 것을 기본 실패 방식으로 삼는다. 긴 페이지에서는 현재 화면과 500px 이내의 문단을 먼저 처리하고, 나머지는 스크롤로 가까워질 때 번역한다. X·YouTube·BOOTH처럼 DOM을 자주 교체하는 화면에서는 중첩된 변경 범위를 한 번만 스캔하며, 모델 호출 직전에 끊어졌거나 화면에서 멀어진 작업은 폐기한다.

이 스케줄링 정책은 목표 언어와 무관하다. 번역 캐시는 목표 언어별로 분리되므로 처음 선택한 언어의 첫 페이지 번역은 기존 언어보다 느릴 수 있지만, 화면 밖 문단이나 사라진 DOM 때문에 콜드 캐시 비용이 불필요하게 커지지 않도록 제한한다. 같은 배치에 동일한 원문과 감지 언어가 반복되면 번역 엔진은 공급자 호출을 한 번만 수행하고 결과를 공유한다.

## 개인정보와 데이터

- 지원 사이트의 허용 영역에서 화면에 나타난 텍스트만 추출한다.
- 입력창, DM, 결제, 주문, 계정, 코드 영역은 추출하지 않는다.
- 페이지 HTML, 쿠키, 로그인 토큰, 브라우징 기록은 읽거나 전달하지 않는다.
- 앱 진단 로그에는 웹페이지 본문과 번역 프롬프트를 기록하지 않는다.
- 로컬 모델을 선택하면 텍스트는 PC 밖으로 나가지 않는다.
- DeepL이나 구독형 외부 번역기를 선택하면 추출된 허용 영역 텍스트가 해당 공급자에게 전달된다. 이 경계는 Discord 표시 번역과 같다.

## 검증

```powershell
npm run test:extension
cargo test --manifest-path src-tauri/Cargo.toml browser_translation
cargo test --manifest-path src-tauri/Cargo.toml browser_bridge::tests
```

실브라우저 검증은 Chrome과 Whale 양쪽에서 각각 수행한다.

1. 확장 팝업이 Windows 앱의 버전·모델·대상 언어를 읽는지 확인한다.
2. 한 문단에 링크와 굵은 글자가 섞인 테스트 문단을 번역한다.
3. 요소 구조와 링크 목적지가 그대로인지 확인한다.
4. 원문 복원을 누르고 모든 텍스트가 정확히 되돌아오는지 확인한다.
5. GitHub 코드, BOOTH 가격, Google 검색창, YouTube 입력창, X 작성창과 DM이 변하지 않는지 확인한다.

현재 프로토타입은 실시간 YouTube 자막, PDF, 이미지 안의 글자, 사용자가 선택한 임의 사이트를 처리하지 않는다. 이 기능들은 각각 별도 권한과 데이터 경계가 필요한 후속 작업이다.
