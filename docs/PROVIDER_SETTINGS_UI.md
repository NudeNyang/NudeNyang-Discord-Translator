# 번역 서비스 연결 화면 · 0.7.7-beta

OpenAI 호환 API의 긴 입력 폼만 아코디언으로 접는다. ChatGPT·Claude·Gemini·DeepL의 행 구성,
상태 설명, 설치·로그인·연결 해제 버튼과 DeepL 키 입력은 기존 위치와 동작을 유지한다.
OpenAI 호환 API도 이름·현재 사용 표시·연결 상태·연결 해제 버튼은 폼 밖에 항상 표시한다.

- OpenAI 행의 펼침 버튼은 `aria-expanded`, `aria-controls`와 패널의 `aria-labelledby`를 연결한다.
  처음에는 폼을 접고 Enter·Space·Tab 조작을 지원한다.
- 입력 폼 DOM을 제거하지 않으므로 서버 주소·모델·API 키·고급 옵션은 접었다 펼쳐도 유지된다.
  아코디언 상태나 입력 중인 키를 별도 저장소에 기록하지 않는다.
- 연결 안내에서 OpenAI 설정으로 이동하면 폼을 펼치고 버튼에 초점을 둔다.
  비동기 연결 실패 시 폼을 다시 펼치며 상태 새로고침만으로 펼침 상태를 바꾸지 않는다.
  접힌 입력란의 URL·숫자 유효성 검사가 실패해도 바깥 폼을 펼쳐 오류 입력란에
  브라우저가 초점을 줄 수 있게 한다.
- 서버 주소·모델 ID·선택형 API 키·저장 버튼은 기본 영역에 둔다.
  요청당 문장 수·동시 요청 수·문맥 공유는 구분선과 작은 ‘고급 설정’ 제목 아래 항상 표시한다.
  안쪽에 별도 아코디언을 두지 않으며 바깥 OpenAI 폼의 접기 동작만 유지한다.
  외부 서버로 텍스트가 전송된다는 안내는 고급 설정 밖에 유지한다.
- 기존 색상·글꼴·아이콘·버튼·커스텀 툴팁을 재사용하며 나머지 설정 화면은 변경하지 않는다.

## 검증 방법

- `npm run test:web`: 실제 마크업을 사용하는 DOM 검사와 기존 설정·인증·다국어 회귀 검사.
- `npm run test:locales`: 고급 설정 문구를 포함한 28개 인터페이스 언어 사전 완전성 검사.
- `npx playwright test --config web/e2e/playwright.config.mjs`: 실제 앱 HTML·CSS·JavaScript를
  Chromium에서 실행한다. 기존 버튼의 가시성, 접기·키보드·입력 보존·상태 갱신·설정 안내 이동,
  연결 실패와 재시도, 밝은/어두운 테마, 320~1100px 배치와 독일어·아랍어를 검사한다.
- 화살표는 기존 SVG 경로를 고정된 아이콘 영역에서 회전한다. CSS 테두리와 회전 뒤 위치 보정을
  섞었을 때 가로로 약 1.4px 치우치던 실패를 재현했다. 접힘·펼침 상태와 100%·125%·150%·200%
  배율에서 아이콘 영역과 실제 경로의 중심이 버튼 중심과 0.1px 이내로 일치하는지 검사한다.

브라우저 검사는 Tauri 명령 경계만 모사하며 사용자 자격 증명과 외부 서버를 사용하지 않는다.
실제 상용 API 인증이나 네이티브 WebView의 동작 전체를 보증하지 않는다.
개발자판 확인을 거친 0.7.7-beta를 사용자 요청에 따라 GitHub 정식 최신 릴리스로 게시한다.
두 설치형의 서명·공개 파일 검증 후 기존 자동 업데이트 목록을 갱신한다.

## 초기 아코디언 검사 결과 (2026-09-28)

- 화면 단위 검사 274개, 랜딩 38개, 확장 469개, 사전 9개 통과.
- 설정 화면 Chromium E2E 6개 및 전체 `npm run test:e2e` 199개 통과.
- UI 로케일 28개 언어·692개 문구 완전성 검사와 Rust 포맷 검사 통과.
- 기존 네 서비스 행의 마크업은 변경 전과 동일함을 별도로 비교했다.

확장 로케일 생성물은 검사에 필요한 LF로 생성한 뒤 원래 체크아웃 상태로 복원했다.
문구 변경이나 검사기 우회는 없다. 실제 상용 API 로그인과 ARM64 실기기 실행은 검사하지 않았다.

## 고급 설정 상시 표시 후속 변경

안쪽 아코디언을 제거하고 정적인 제목·구분선으로 바꿨다. 기존 화면 단위 검사 274개,
설정 화면 Chromium E2E 6개, UI 로케일 검사와 Rust 포맷 검사를 다시 실행해 통과했다.
바깥 폼을 펼치면 고급 옵션도 즉시 보이며 입력 보존·오류 입력란 표시·화살표 중앙 정렬을 유지한다.
이번 변경에서는 확장 전체 E2E를 다시 실행하지 않았다. 위 199개 통과는 초기 변경 당시 결과다.

## 펼침 시 헤더 위치 유지

기존에는 행 전체의 최소 높이 84px을 입력 폼과 공유해, 펼치면 헤더의 여유 공간이
줄면서 아이콘과 이름이 10.5px 위로 이동했다. 헤더를 독립된 레이아웃으로 분리하고
기존 높이·여백·구분선을 유지해 입력 폼만 아래로 추가한다. 고정 픽셀 위치 보정은 사용하지 않는다.
설정 E2E에 320~1100px 너비와 100%·125%·150%·200% 배율의 위치 회귀 검사를 추가했다.
아이콘·이름·상태·펼침 버튼의 행 기준 좌표와 크기를 비교하며, 키보드로 열고 닫는다.
수정 전 10.5px 차이로 실패한 검사가 수정 후 통과했고 설정 E2E 전체 7개를 통과했다.

## 정식 게시 전 재검증

0.7.7-beta 공개용 소스에서 `npm test` 790개(화면 274·랜딩 38·확장 469·사전 9),
`cargo test --manifest-path src-tauri/Cargo.toml --locked` 510개(환경 전용 50개 제외),
전체 `npm run test:e2e` 199개와 설정 화면 E2E 7개를 다시 실행해 통과했다.
UI 로케일 검사와 Rust 포맷 검사도 통과했다. 모사 서버·페이지를 쓰는 검사이며
공개 웹 표본 검사와 실제 외부 API 인증, ARM64 실기기 검사는 포함하지 않는다.


## 0.7.9-beta 개발자판: 번역 결과 검사

번역 엔진 하단의 고급 설정에 전역 스위치를 둔다. 기본값은 켜짐이며 기존 설정 파일에
값이 없어도 켜짐으로 읽는다. OpenAI 호환 API만의 옵션으로 오해하지 않도록 연결 폼과
분리하고, 이 영역에는 별도 아코디언을 추가하지 않는다.

설명은 상태에 따라 바꾸지 않는다. “원문이 그대로 남거나 번역이 불완전해 보이면 다시
번역합니다. 코드나 고유명사가 불필요하게 재번역되는 경우 끌 수 있습니다.”를 고정 표시한다.
버튼의 접근성 이름은 제목에, 설명은 도움말에 연결한다. 이 옵션을 꺼도 빈 응답은
거부하며 통신 오류 처리와 보호 문자 복원은 유지한다.
