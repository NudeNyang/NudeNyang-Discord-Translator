# 로컬 저장 공간 정리 — 2026-10-31

사용자 요청으로 Home·Forest·태블릿의 재생성 가능한 로컬 캐시/구버전 빌드 산출물을 정리했습니다. 별도 확인으로 NudeNyang Translator Rust 빌드 캐시도 포함했습니다.

## 정리 및 보존

- 닫힌 Home·Forest·First Install World의 Unity Library/Logs와 제품 Library의 실제 D 드라이브 캐시를 정리했습니다. 제품 Library 연결 경로는 유지하고 대상 디렉터리를 빈 상태로 복구했습니다.
- Companion 설치/배포본은 0.22.12와 0.22.11, 태블릿 패키지는 1.0.2와 1.0.1을 보존했습니다. 이전 버전의 로컬 산출물만 제거했으며 R2는 변경하지 않았습니다.
- `test_legacy_update_matrix.py`가 만드는 구버전 설치 시험 복사본과 하루 이상 지난 Companion `test-*` 격리 실행 출력, Translator `src-tauri/target`을 정리했습니다.
- Home Git LFS 임시 파일은 1시간 이상 지난 파일 228개를 배타적 읽기 및 시각/크기 재검사 후 제거했습니다. 해당 디렉터리의 실제 저장 위치는 D 드라이브입니다. `.git/lfs/objects`와 Git 이력은 보존했습니다.
- 원본 에셋·씬·코드·설정, 기존 수정, UserSettings 업데이트/씬 복구 백업, Temp의 씬 복구 파일, 연결된 브라우저 확장과 설치된 Companion/Translator 실행 파일을 보존했습니다. 실행 중인 sodanen-home 및 VRChat 캐시와 관계없는 다른 프로젝트는 정리하지 않았습니다.

## 검증

- 직접 삭제한 파일의 논리 크기 합계: C **67.28GiB**, D **36.39GiB**, 총 **103.67GiB**. 삭제 계획 872개 경로 및 LFS 임시 파일 228개를 처리했으며 실패/사용 중 건너뜀은 없습니다.
- C 여유 공간은 시작 **119.21GiB**에서 정리 후 **216.23GiB**로 증가했습니다. 사용자 프로젝트 종료 및 다른 프로세스의 동시 파일 변경이 있으므로 여유 공간 변화와 직접 삭제량은 동일하지 않습니다.
- 문서 갱신 전 Home 5,884개, 제품 15,128개, Forest 1,945개, Translator 460개, 총 **23,417개 Git 관리 파일의 SHA-256이 정리 전후 동일**했습니다. 기존 Git 상태도 네 저장소에서 동일했습니다.
- 삭제 대상 잔존 파일은 0개였습니다. 보존 버전 6개 디렉터리의 파일 존재/개수/용량 및 두 설치 앱의 실행 파일 존재를 확인했습니다. First Install World는 별도 Git 저장소가 없는 시험 프로젝트이며 Library/Logs만 제거했습니다.
- 상세 로컬 계획·파일/대상별 삭제 결과·원본 해시 비교는 Home `LocalOnly/StorageCleanup20261031`에 보존합니다. 사용자 경로·기존 작업 상태를 포함한 이 기록은 Git에 추가하지 않습니다.

## 한계 및 후속
