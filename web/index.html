설정

Discord DOM 번역과 로컬 모델, 이미지 OCR을 한곳에서 관리합니다.

엔진 연결 중

기본 번역

실시간 번역

Discord 메시지와 채널명을 선택한 언어로 번역해 표시합니다.

보내는 메시지 번역

최근 대화 언어를 기준으로 입력한 메시지를 번역한 후 전송합니다.

기본 전송 언어

채널별 선택이 없는 경우 적용할 전송 언어를 지정합니다.

자동 감지 결과 확인

자동 감지한 언어를 채널에 처음 적용하기 전에 확인합니다.

표시 언어

원문과 표시 언어가 같으면 번역하지 않고 그대로 유지합니다.

번역 모델

로컬 Hy-MT2와 구독 CLI, 외부 API 중에서 선택합니다.

번역 말투

원문 말투를 유지하거나 존댓말과 반말로 고정할 수 있습니다.

Hy-MT2 실행 장치

자동 설정은 GPU를 우선 사용하고 필요한 경우 CPU로 전환합니다.

로컬 모델 예열 유지

번역을 꺼도 모델을 VRAM에 유지합니다. 끄면 즉시 반환합니다.

화면 확인 빈도

값이 높으면 반응은 빨라지지만 CPU 사용량이 증가할 수 있습니다.

로컬 우선 Hy-MT2와 이미지 OCR은 PC에서 실행됩니다. 외부 모델은 추출된 텍스트만 전송합니다.
