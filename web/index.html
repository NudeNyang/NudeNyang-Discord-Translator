번역 엔진

받은 메시지는 빠른 로컬 모델로, 보낼 메시지는 문맥과 말투에 강한 CLI 모델로 번역하는 구성을 권장합니다.

표시 언어 번역 모델

많은 메시지와 이미지를 계속 처리하므로 빠른 로컬 모델 사용을 권장합니다.

보내는 메시지 통역 모델

의미와 말투를 자연스럽게 전달하도록 품질 우선 CLI 모델 사용을 권장합니다.

권장 품질을 사용하려면 CLI 모델 연결이 필요합니다. CLI 모델은 로컬 모델보다 문맥과 말투를 안정적으로 보존합니다. 번역할 메시지 텍스트만 선택한 서비스로 전송됩니다.
VRAM 보호로컬 모델은 하나만 실행됩니다. 표시 번역과 보내는 메시지 통역의 로컬 모델 선택은 함께 변경됩니다.

CLI 및 번역 서비스 연결

위에서 선택한 서비스 하나만 연결하면 됩니다. 다른 서비스는 필요할 때 연결할 수 있습니다.

로컬 엔진

로컬 번역 모델의 실행 장치와 자원 사용 방식을 설정합니다.

시스템 메모리를 확인하고 있습니다.선택한 로컬 모델의 메모리 요구량을 계산합니다.

로컬 모델 실행 장치

자동 보호는 GPU를 사용하다 VRAM이 부족해지면 현재 번역을 마친 뒤 CPU/RAM으로 전환합니다.

로컬 모델 예열 유지

켜두면 다시 번역할 때 빠르게 반응하지만 RAM/VRAM을 계속 사용합니다. 게임이 느려지거나 메모리가 부족하다면 꺼주세요.

화면 확인 빈도

값이 높을수록 반응이 빨라지며 CPU 사용량이 증가할 수 있습니다.

저장 공간 관리

다운로드한 로컬 모델과 번역 기록을 관리합니다.

로컬 번역 모델

이미지 번역

Discord 이미지에서 글자를 감지하고 번역하여 표시합니다.

기본 기능

이미지 OCR 자동 번역

실시간 번역이 켜져 있을 때 Discord 이미지의 글자를 PC에서 감지하여 표시 언어로 번역합니다. 번역이 꺼져 있으면 이미지에 별도 버튼이나 안내 문구를 표시하지 않습니다.

이미지 OCR 품질

글자 모양과 배경에 따라 인식 속도와 정확도를 조절합니다.

자동 처리빠른 모델로 먼저 인식하고 불확실한 영역만 고품질 모델로 다시 확인합니다.
고품질 모델약 70MB이며 처음 필요할 때 다운로드합니다. 5분 동안 사용하지 않으면 메모리에서 해제됩니다.

사전

Discord에서 선택한 단어의 뜻을 확인하고 개인 용어와 오프라인 사전팩을 관리합니다.

Aa
선택형 사전

메시지 안에서 바로 뜻 확인

Discord 메시지에서 단어나 짧은 구절을 대략 선택한 뒤 Aa 버튼을 누르면, 사전이 일치하는 표현을 나누어 뜻과 발음을 찾습니다. 개인 용어와 설치된 사전팩은 PC 안에서만 조회합니다.

선택한 구절 전체와 인터페이스 언어에 없는 사전 뜻은 설정된 번역 모델로 자동 번역될 수 있습니다. 외부 모델을 선택했다면 해당 텍스트가 그 서비스로 전송될 수 있습니다. 주변 문맥은 PC 안에서만 사용합니다.
