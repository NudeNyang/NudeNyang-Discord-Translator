설정

번역

받는 메시지와 보내는 메시지의 번역 방식을 설정합니다.

01

받는 메시지

Discord에서 표시할 번역을 설정합니다.

실시간 번역

메시지와 채널명을 번역하여 표시합니다.

표시 언어

원문과 같은 언어는 그대로 표시합니다.

02

보내는 메시지

입력한 메시지를 번역한 후 전송합니다.

보내는 메시지 번역

최근 대화 언어를 기준으로 번역합니다.

기본 전송 언어

채널별 선택이 없을 때 적용합니다.

채널별 첫 감지 확인

자동 감지된 언어를 채널별로 처음 사용할 때 한 번만 확인합니다.

03

공통 번역 규칙

받는 메시지와 보내는 메시지에 공통으로 적용합니다.

번역 말투

원문 말투를 유지하거나 원하는 말투로 고정합니다.

번역 엔진

번역 모델, 로컬 실행 방식 및 외부 번역 서비스를 설정합니다.

번역 모델

로컬 Hy-MT2, 구독 CLI 또는 외부 API를 선택합니다.

L

로컬 엔진

Hy-MT2의 실행 장치와 자원 사용 방식을 설정합니다.

Hy-MT2 실행 장치

자동 설정은 GPU를 우선 사용하고 필요한 경우 CPU로 전환합니다.

로컬 모델 예열 유지

번역을 꺼도 모델을 VRAM에 유지합니다.

화면 확인 빈도

값이 높을수록 반응이 빨라지며 CPU 사용량이 증가할 수 있습니다.

로컬 우선Hy-MT2와 이미지 OCR은 PC에서 실행됩니다. 외부 모델에는 추출된 텍스트만 전송됩니다.

번역 서비스 연결

구독 계정과 API 연결 상태를 관리합니다.

ChatGPT 구독 · Codex CLI

확인 중Codex CLI와 로그인 상태를 확인하고 있습니다.
C

Claude Pro/Max · Claude Code

확인 중Claude Code와 로그인 상태를 확인하고 있습니다.

Google 구독 · Gemini CLI

확인 중Gemini CLI와 로그인 상태를 확인하고 있습니다.
D

DeepL

API 사용량 과금

확인 중저장된 API 키를 확인하고 있습니다.

구독 서비스 인증은 각 공식 CLI에서 관리하며 API 키는 운영체제 보안 저장소에 보관합니다.

이미지 번역

Discord 이미지에서 글자를 감지하고 번역하여 표시합니다.

기본 기능

이미지 OCR 자동 번역

실시간 번역이 켜져 있을 때 Discord 이미지의 글자를 PC에서 감지하여 표시 언어로 번역합니다. 번역이 꺼져 있으면 이미지에 별도 버튼이나 안내 문구를 표시하지 않습니다.

처리 위치OCR은 PC에서 실행됩니다.
번역 언어번역 메뉴의 표시 언어 설정을 따릅니다.
표시 조건실시간 번역이 켜져 있을 때만 활성화됩니다.

편의 기능
