작동 방식과 개인정보

필요한 범위만 연결하고, 선택한 방식으로 번역합니다.

Discord 사용자 토큰과 self-bot을 사용하지 않으며 설치 파일과 서버 데이터를 수정하지 않습니다.

로컬 번역

로컬 AI를 선택하면 번역할 텍스트를 외부 번역 서비스로 전송하지 않습니다.

온라인 번역

선택한 서비스에 필요한 텍스트만 전달하며 인증은 각 공식 방식으로 관리합니다.

이미지 처리

이미지는 PC에서 인식하며 외부 서비스에는 추출된 텍스트만 전달합니다.

설정은 단순하게, 선택지는 분명하게 구성했습니다.

받는 메시지, 보내는 메시지, 이미지 번역과 엔진 연결 상태를 한 화면에서 관리합니다.

설정 화면 사진 라이트 모드 전체 화면 권장 1600 × 1000, PNG

Discord 이용 안내

이 앱은 사용자 토큰이나 비공식 Discord API를 사용하지 않지만, Discord가 공식으로 승인한 도구는 아닙니다. Discord 정책상 클라이언트 변경 또는 일반 사용자 계정 자동화로 판단될 경우 사용이 제한되거나 계정에 조치가 적용될 수 있습니다. 최신 정책을 확인한 뒤 사용 여부를 결정해 주십시오.

사용에 따른 책임은 사용자에게 있습니다.

Discord 이용 약관 플랫폼 조작 정책

자주 묻는 질문

Discord 이용 약관에 위배될 수 있나요?

Discord 정책은 클라이언트 변경과 일반 사용자 계정 자동화를 허용하지 않는다고 안내합니다. 이 앱은 공식 승인을 받은 도구가 아니므로 정책 위반으로 판단될 가능성을 배제할 수 없습니다. 사용 여부와 결과에 대한 책임은 사용자에게 있습니다.

Discord 계정 토큰이 필요한가요?

필요하지 않습니다. 사용자 토큰이나 비공식 Discord API를 사용하지 않습니다.

번역 내용이 외부로 전송되나요?

로컬 모델을 선택하면 외부 번역 서비스로 전송되지 않습니다. 온라인 서비스를 선택하면 필요한 텍스트만 해당 서비스에 전달됩니다.

이미지 원본도 외부 서비스에 전달되나요?

아닙니다. 이미지의 글자는 PC에서 인식하며 선택한 외부 번역기에는 추출된 텍스트만 전달합니다.

어떤 운영체제를 지원하나요?

현재 Windows 10과 Windows 11의 x64 환경을 지원합니다. macOS는 아직 지원하지 않습니다.

Discord 업데이트 이후에도 계속 작동하나요?

Discord가 공식으로 제공하는 확장 방식이 아니므로 클라이언트 업데이트에 따라 일시적으로 작동하지 않을 수 있습니다.

Discord 대화를 원하는 언어로 확인해 보십시오.

현재 Windows 10·11 x64 환경을 지원합니다.
