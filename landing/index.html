앱 지원 언어

번역하려고 별도의 번역기를 켤 필요가 없습니다.

메시지와 답장은 물론, 이미지 속 글자까지 Discord 안에서 바로 번역합니다.

  1. 언어 자동 감지여러 언어가 동시에 표시되어도 메세지별 언어를 자동으로 감지해 번역합니다.
  2. 실시간 화면 번역받은 메시지와 채널명을 Discord 화면에서 바로 번역합니다.
  3. 전송 메시지 통역작성한 문장을 확인하고 상대방의 언어로 번역해 보냅니다.

자체 서버 없음

회원가입이나 서버 연결 없이 앱이 PC에서 직접 동작합니다.

대화 내역을 수집하지 않음

대화 내용, 이미지와 번역 기록을 수집하거나 보관하지 않습니다.

Discord 데이터 그대로 유지

Discord 사용자 토큰과 self-bot을 사용하지 않으며 설치 파일과 서버 데이터를 수정하지 않습니다.

온라인 번역 엔진을 선택하면 번역에 필요한 텍스트가 해당 서비스로 직접 전달될 수는 있습니다.

번역 방식부터 언어까지 원하는 대로 설정하세요.

받는 메시지, 보내는 메시지, 이미지 번역과 엔진 연결 상태를 한 화면에서 관리합니다.

Discord 이용 전 확인해 주세요

이 앱은 사용자 토큰이나 비공식 Discord API를 사용하지 않습니다. 다만 Discord가 공식적으로 승인한 도구는 아니며, 정책 해석에 따라 이용이 제한될 수 있습니다. 사용 전 최신 정책을 확인해 주세요. 최종적인 이용 판단과 그에 따른 책임은 사용자에게 있습니다.

Discord 이용 약관 플랫폼 조작 정책

자주 묻는 질문

Discord 이용 약관에 위배될 수 있나요?

Discord 정책은 클라이언트 변경과 일반 사용자 계정 자동화를 허용하지 않는다고 안내합니다. 이 앱은 공식 승인을 받은 도구가 아니므로 정책 위반으로 판단될 가능성을 배제할 수 없습니다. 사용 여부와 결과에 대한 책임은 사용자에게 있습니다.

대화 내용이나 개인정보를 수집하나요?

NudeNyang Translator는 별도의 운영 서버가 없으며 대화 내용, 이미지, 번역 기록과 개인정보를 수집하거나 보관하지 않습니다. 단, 온라인 번역 엔진을 선택하면 번역에 필요한 텍스트가 해당 서비스로 직접 전달될 수 있습니다.

Discord를 따로 개조하거나 플러그인을 설치해야 하나요?

아니요. 별도의 클라이언트 개조 도구나 플러그인을 설치할 필요 없이, 공식 Discord 데스크톱 앱을 그대로 사용하면서 번역 기능을 이용할 수 있습니다.

유료인가요?

NudeNyang Translator는 무료 오픈소스 프로그램입니다. 단, 선택한 외부 번역 서비스에 따라 별도의 구독이나 API 비용이 발생할 수 있습니다.

어떤 운영체제를 지원하나요?

현재 Windows 10과 Windows 11의 x64 환경을 지원합니다. macOS는 아직 지원하지 않습니다.

Discord 업데이트 이후에도 계속 작동하나요?

Discord가 공식으로 제공하는 확장 방식이 아니므로 클라이언트 업데이트에 따라 일시적으로 작동하지 않을 수 있습니다.
